よくある質問

アカウントを作る必要はありますか？

いいえ。インストールしてすぐに記録できます。記録は端末に保存され、登録をお願いすることはありません。

機種変更をすると記録はどうなりますか？

同じOSの端末どうしなら、メニュー → アプリ設定 → デバイス間の同期をオンにしてください。iPhone・iPadはiCloudで、AndroidはGoogleドライブで、同じアカウントの端末どうしの記録をそろえます。無料で使え、写真・動画のファイルとサブスクリプションの状態は移しません。

iPhoneとAndroidの間で移したり、ファイルで保管したりするには、メニュー → データの移行・バックアップ → バックアップファイルを作成でファイルを作って新しい端末に送り、同じ画面のバックアップファイルを読み込むで開きます。ファイルの作成、記録の置き換え、パスワードの設定は無料で、今の記録に加える統合はPROの機能です。

端末のバックアップ（iCloudまたはGoogleの自動バックアップ）がオンなら、新しい端末でアプリを復元するときにも一緒に引き継がれます。

無料でどこまで使えますか？

ワークアウトの記録は件数の制限なく無料です。ルーティンは3件、カスタム種目は5件まで作れます。

1,690種目と動作ガイド、3・5・8・10回の推定重量、プレート計算、デバイス間の同期、kgとlbの単位、トレーナーへの送信も無料です。

PROとPRO+では何が変わりますか？

PROは次に挙げる重量を計算します。ルーティンの自動増量、1〜15回の個人用回数-重量カーブ、ワークアウト中のコーチ、自分の記録から学ぶ基準、筋力バランスの処方、停滞の検知、器具に合わせた推奨重量、週間コーチングレポートが含まれ、ルーティン、カスタム種目、受け取った会員の記録を件数の制限なく使えます。

PRO+はPROのすべての機能に、ブロックピリオダイゼーションの計画、その日のコンディションに合わせた強度調整、筋肉ごとの週間セット数の調整、栄養目標、ウォームアップセットの自動入力を加えます。

どちらも月額または年額のサブスクリプションです。

サブスクリプションはどう解約しますか？

決済はAppleまたはGoogleのアカウントで処理されるため、解約もそちらで行います。

  • iOS：設定 → ユーザ名 → サブスクリプション
  • Android：Playストア → プロフィール → お支払いと定期購入 → 定期購入

更新日の24時間前までに解約しない場合は、自動的に更新されることがあります。

機種変更したらPROが表示されません

メニュー → FitBoost PRO → 購入を復元をタップしてください。購入したAppleまたはGoogleのアカウントでサインインしている必要があります。

サブスクリプションは支払ったストアのアカウントに結び付いているため、iPhoneで購入したサブスクリプションはAndroidでは復元できません。その逆も同じです。

次の重量はどう計算されますか？

12回以下の完了セットから、Epley・Brzycki・Lombardiの推定式の中央値で1RMを求めます。RIRを残すと、残っていた回数まで反映します。記録が増えると、種目ごとの回数-重量の特性もあわせて使います。

推奨値はトレーニング計画のための参考値であり、医療上の助言ではありません。痛みや普段と違う疲労がある場合は重量を下げ、専門家にご相談ください。

ポンドで記録できますか？

はい。メニュー → アプリ設定 → 一般設定 → 重量単位でキログラムとポンドから選べます。プレート計算も選んだ単位で行います。

言語を変えたい

メニュー → アプリ設定 → 言語で、한국어、English、日本語、简体中文、繁體中文から選べます。「システム設定」を選ぶと端末の言語に合わせます。

テーマカラーを変えたい

メニュー → アプリ設定 → テーマ変更で6色から選べます。

トレーナーと記録を共有できますか？

はい。メニュー → トレーナーに送るで期間を選ぶと、レポート（PDF）と会員ファイルを作成し、メッセンジャーやメールなどお好きなアプリで送れます。私たちのサーバーは経由しません。

トレーナーは受け取ったファイルをFitBoostで開き、メニュー → 会員の記録で確認します。受け取った記録はトレーナー自身の記録と混ざりません。無料では会員1人まで、PROでは制限なく見られます。

友だち探しのようなソーシャル機能は、現在の配布版にはありません。

スマートウォッチでも使えますか？

Apple Watch（iPhoneと組み合わせて）、Galaxy WatchなどのWear OSウォッチ（Androidと組み合わせて）、Garminウォッチ（iPhone・Androidと組み合わせて）に対応しています。ウォッチでセットを終えて強度を選ぶと休憩タイマーが動き、終わると振動で知らせます。ウォッチで終えたワークアウトはスマートフォンの記録に入ります。

スマートフォンでメニュー → アプリ設定 → スマートウォッチ設定のスマートウォッチ連携をオンにしてください。GarminはConnect IQストアからウォッチにFitBoostをインストールしたあと、同じ画面のGarminウォッチを接続をタップします。Garminウォッチで行ったワークアウトはGarmin Connectにも筋力トレーニングとして残ります。

トレーニングプログラムを組んでくれますか？

ホーム → プログラム → 自分に合うプログラムを作るで、目標・運動経験・週の日数・1回の時間・器具を選ぶと、週間プログラムを組んでルーティンとして保存します。

無料ではルーティン3件の上限内で保存でき、別の構成を見る機能と種目を変えて作り直す機能はPROです。

記録をなくさないために

  • デバイス間の同期か、端末のバックアップをオンにしておきましょう。
  • ときどきバックアップファイルを作成で、ファイルを別に保管しましょう。
  • アプリを削除すると、端末にあったアプリのデータも一緒に削除されます。
