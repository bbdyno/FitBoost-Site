选择分享卡片

在跑步结果中点 {{> runShareOpen}}，从 {{> runShareKindRoute}}、{{> runShareKindSplits}}、{{> runShareKindPhoto}}、{{> runShareKindSticker}} 卡片中选一种，做成快拍或帖子尺寸。

  1. 在跑步结果页面点 {{> runShareOpen}}。过去的跑步可在 {{> tabRecord}} 中打开。
  2. 在上方的标签行选择卡片，再选择 {{> shareFormatStory}} 或 {{> shareFormatFeed}} 尺寸和背景色。
  3. 打开或关闭 {{> runShareShowRoute}}、{{> runShareShowHeartRate}}、{{> runShareShowAscent}} 等项目。
  4. 点 {{> shareToInstagramStory}} 会直接打开 Instagram 快拍。要发到别处或保存到相册，请用 {{> shareOtherApps}}。

{{> runShareKindSticker}} 卡片背景透明，会作为可移动的贴纸放进快拍。路线只按截掉起点和终点附近及隐私区域后的线绘制，卡片中不含底图、坐标和时刻（含日期）。力量训练可在 {{> tabRecord}} 中打开记录后用 {{> shareWorkoutSummary}}，或在 {{> tabStats}} 中用 {{> shareCardsTooltip}}，以同样方式制作卡片。

打开装饰编辑器

点跑步或力量训练分享页面上方的魔杖按钮（{{> studioOpen}}），即可打开装饰编辑器。

  1. 点分享页面右上角的魔杖按钮。
  2. 从下方栏打开 {{> studioPanelStickers}}、{{> studioPanelFonts}}、{{> studioPanelColors}}、{{> studioPanelPhoto}}、{{> studioPanelLayers}}、{{> studioPanelTemplates}}。
  3. 加入贴纸后用手指拖动，或调整大小和旋转。用 {{> studioAddText}} 也可以加文字。
  4. 在 {{> studioCanvasSize}} 中选择 {{> shareFormatStory}}、{{> shareFormatFeed}} 或 {{> studioSquare}}，完成后导出或发到快拍。

跑步贴纸有距离、时间、配速、海拔剖面和跑过的路线，力量贴纸有 {{> studioMetricLiftSummary}}、{{> studioMetricLiftRecord}}、{{> studioMetricBigThree}}、{{> studioMetricVolumeVsLast}}、{{> studioMetricSetChips}}、{{> studioMetricMuscles}} 等。坡度修正配速或估算 1RM 走势这类分析值贴纸，按该值原本所属的等级开放。卡片上的应用名称标识与等级无关，始终会显示。

字体、颜色与照片

即使在同一个贴纸里，也能为 {{> studioPartValue}}、{{> studioPartUnit}}、{{> studioPartLabel}} 分别选择字体和颜色。照片可以从黑白、模糊调整到亮度、对比度。

  • {{> studioPanelFonts}}：每个部分的字体、{{> studioFontSize}}、{{> studioLetterSpacing}}、{{> studioTabular}}。字体中没有的字会提示 {{" studioFontFallback}}。
  • {{> studioPanelColors}}：基本 3 色、从照片中取的颜色、{{> studioEyedropper}}、{{> studioHex}}。会显示对比度以判断文字是否清晰，并建议 {{> studioAddShadow}}。
  • {{> studioPanelPhoto}}：{{> studioGrayscale}}、{{> studioBlur}}、{{> studioBrightness}}、{{> studioContrast}}、{{> studioWarmth}}、{{> studioBottomShade}}。
  • {{> studioRoute}}：{{> studioRouteSolid}}，或按 {{> studioRoutePace}}、{{> studioRouteGrade}} 给线上色。
  • {{> studioPanelLayers}}：{{> actionUndo}}、{{> studioRedo}}、{{> studioLayerUp}}、{{> studioLayerDown}}、{{> studioLayerHide}}、{{> studioLayerLock}}、位置与旋转数值、{{> studioSafeArea}}。

共有 22 种字体，全部以 SIL 开源字体许可（OFL）收录在应用中。免费可在整个贴纸上使用 3 种基本字体，以及基本 3 色、黑白、模糊和单色路线。每个部分单独选字体和其余字体、照片取色、吸管、色码、撤销、图层、数值、遮挡区域、路线上色，以及亮度、对比度、暖色、底部变暗属于 PRO。

放到人物后面 PRO

在 {{> studioPanelPhoto}} 中打开 {{> studioSubjectFront}}，会抠出照片中的人物，让贴纸位于人物后面。照片只在设备内处理。

  1. 在 {{> runShareKindPhoto}} 卡片或编辑器中选择照片作为背景。
  2. 在 {{> studioPanelPhoto}} 中打开 {{> studioSubjectFront}}。

{{" studioSubjectFrontHint}}。iPhone 使用设备自带的视觉功能，Android 使用应用内置的人物分割模型，因此照片不会发送到任何地方。人物太小或模糊时会显示 {{" studioNoPerson}}。

我的模板与自动生成

用 {{> studioTemplateSave}} 保存装饰好的布局、字体和颜色，下次记录的数值会直接填进去（PRO）。

  1. 在编辑器中排好布局后，点 {{> studioPanelTemplates}} 中的 {{> studioTemplateSave}}。
  2. 下次分享时在 {{> studioPanelTemplates}} 中选择该模板，就会填入新记录的数值。
  3. 打开模板的 {{> studioTemplateAutoOn}} 开关后，训练或跑步结束时可从结果页面的 {{> studioOpenAuto}} 直接打开（PRO+）。

我的模板只保存在本设备和备份文件中，不会通过设备间同步上传。订阅结束后，已保存的模板不会删除，只是 PRO 功能重新锁定。

分享与装饰的免费与付费

分享卡片和基本装饰免费。专业编辑工具属于 PRO，结束后用我的模板直接生成属于 PRO+。

  • 免费：跑步与力量分享卡片，贴纸的添加、拖动、大小与旋转，3 种基本字体，基本 3 色，黑白与模糊，单色路线，快拍、帖子与正方形尺寸，导出和直接发到 Instagram 快拍。
  • PRO：每个部分的字体、大小、字距与数字宽度，其余字体，照片取色、吸管与色码，撤销、图层、数值与快拍遮挡区域，路线上色，亮度、对比度、暖色与底部变暗，放到人物后面，我的模板。
  • PRO+：训练或跑步结束时用我的模板直接生成分享卡片。

卡片上的应用名称标识在所有等级中都会显示，没有去除功能。
