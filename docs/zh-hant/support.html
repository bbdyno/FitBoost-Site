    常見問題

    需要註冊帳號嗎？

    不需要。安裝後即可開始記錄。紀錄儲存在裝置上，我們不要求註冊。

    更換裝置後，紀錄會怎樣？

    相同作業系統的裝置之間，請開啟選單 → 應用程式設定 → 裝置間同步。iPhone、iPad 透過 iCloud，Android 透過 Google 雲端硬碟，在使用同一帳號的裝置之間同步紀錄。同步免費，不會同步照片、影片檔案與訂閱狀態。

    若要在 iPhone 與 Android 之間轉移，或以檔案形式保存，請在選單 → 資料轉移與備份 → 建立備份檔案產生檔案並傳送到新裝置，再於同一畫面透過匯入備份檔案開啟。建立檔案、取代紀錄與設定密碼皆免費；將檔案合併至現有紀錄則需要 PRO。

    若已開啟裝置備份（iCloud 或 Google 自動備份），在新裝置上回復應用程式時紀錄也會一併轉移。

    免費版可以用到什麼程度？

    訓練紀錄免費且不限數量。例行訓練最多可建立 3 個，自訂動作最多 5 個。

    1,690 個動作與動作指南、3·5·8·10 次的預估重量、槓片計算、裝置間同步、公斤與磅兩種單位，以及傳送給教練，也都免費。

    PRO 和 PRO+ 有什麼不同？

    PRO 會計算下次該用多少重量，包括例行訓練自動加重、1–15 次個人次數-重量曲線、訓練中教練、從自身紀錄學習的標準、肌力平衡建議、停滯偵測、配合器材的建議重量與每週訓練報告，且例行訓練、自訂動作與收到的學員紀錄皆不限數量。

    PRO+ 在 PRO 全部功能之上，再加入區塊週期化計畫、依當天狀態調整強度、依肌群調整每週組數、營養目標，以及熱身組自動填入。

    兩者皆提供按月或按年訂閱。

    如何取消訂閱？

    付款透過 Apple 或 Google 帳號處理，因此也需在該平台取消。

    • iOS：設定 → 你的名稱 → 訂閱項目
    • Android：Play 商店 → 個人資料 → 付款和訂閱 → 訂閱

    若未在續訂日前至少 24 小時取消，訂閱可能會自動續訂。

    更換裝置後看不到 PRO

    請點按選單 → FitBoost PRO → 還原購買。需登入購買時使用的 Apple 或 Google 帳號。

    訂閱與付款的商店帳號綁定，因此在 iPhone 上購買的訂閱無法在 Android 上還原，反之亦然。

    下次重量是如何計算的？

    根據 12 次以下的已完成組，取 Epley、Brzycki、Lombardi 公式估算值的中位數作為 1RM。若記錄 RIR，也會計入剩餘可做次數。紀錄累積後，還會結合每個動作本身的次數-重量特性。

    建議值僅為規劃訓練的參考，並非醫療建議。如出現疼痛或異常疲勞，請降低重量並諮詢專業人士。

    可以用磅記錄嗎？

    可以。在選單 → 應用程式設定 → 一般設定 → 重量單位中選擇公斤或磅。槓片計算也會使用所選單位。

    如何變更語言？

    在選單 → 應用程式設定 → 語言中，可選擇 한국어、English、日本語、简体中文、繁體中文。選擇「跟隨系統」則使用裝置語言。

    如何變更主題顏色？

    在選單 → 應用程式設定 → 變更主題中，可從六種顏色中選擇。

    可以與教練分享紀錄嗎？

    可以。在選單 → 傳送給教練中選擇期間，應用程式會產生報告（PDF）與學員檔案，可透過通訊軟體、電子郵件等任何應用程式傳送，不經過我們的伺服器。

    教練以 FitBoost 開啟收到的檔案後，可在選單 → 學員紀錄中查看。收到的紀錄不會與教練本人的紀錄混在一起。免費版可查看 1 位學員，PRO 不限人數。

    目前發布的版本沒有尋找好友等社群功能。

    可以在智慧手錶上使用嗎？

    支援 Apple Watch（搭配 iPhone）、Galaxy Watch 等 Wear OS 手錶（搭配 Android），以及 Garmin 手錶（搭配 iPhone 或 Android）。在手錶上完成一組並選擇強度後，休息計時器會開始計時，結束時以震動提醒。在手錶上完成的訓練會存入手機的紀錄。

    請在手機的選單 → 應用程式設定 → 智慧手錶設定中開啟智慧手錶同步。使用 Garmin 時，請先從 Connect IQ 商店將 FitBoost 安裝到手錶上，再於同一畫面點按連接 Garmin 手錶。以 Garmin 手錶完成的訓練也會以重量訓練活動儲存到 Garmin Connect。

    可以幫我規劃訓練計畫嗎？

    在首頁 → 訓練計畫 → 生成適合我的計畫中，選擇目標、訓練經驗、每週天數、每次時長與器材，應用程式會產生每週計畫並儲存為例行訓練。

    免費版可在 3 個例行訓練的上限內儲存；查看其他組合與更換動作重新生成為 PRO 功能。

    避免遺失紀錄

    • 請開啟裝置間同步或裝置備份。
    • 不時透過建立備份檔案另存一份檔案。
    • 刪除應用程式後，裝置上的應用程式資料也會一併刪除。
