    槓片計算機

    輸入目標重量，就會告訴你每邊要掛哪些槓片。免費。

    在 選單 的 計算機 區域點選 槓片。槓鈴桿重量和手上的槓片請在我的器材中設定，並用計算機裡的 更改 切換器材。

    1RM 與強度計畫計算機

    輸入重量和次數（不超過 15 次），即可估算 1RM。

    在 1RM 計算機 中點選 用這個重量產生強度計畫，會進入 強度計畫計算機，用這個 1RM 計算 5×5、5/3/1、8/6/3 和 GVT 每組的重量。

    有氧、熱量與巨量營養素計算機

    在 選單 的 計算機 區域開啟有氧、熱量和巨量營養素計算機。

    • 有氧熱量計算：根據跑步機速度、坡度或測功儀配速計算消耗熱量。
    • 熱量計算機：根據運動強度（MET）、時長和體重估算消耗熱量。
    • 巨量營養素計算機：計算目標熱量以及碳水、蛋白質和脂肪。

    所有工具都集中在 選單 → 全部工具。

    我的器材

    填好槓鈴桿和槓片、啞鈴和壺鈴的間隔、器材每格配重後，槓片計算會按這套器材進行。

    從 選單 → 應用程式設定 → 訓練與例行 → 我的器材 開啟。免費只能儲存一個地點，儲存多個地點或把推薦重量調整為這套器材能湊出的重量屬於 PRO 功能。

    訓練術語詞典

    在 選單 → 訓練術語詞典 中查詢遞減組、RPE 等不熟悉的詞。

    術語分為組、強度、計畫三類，每條都寫了是什麼、怎麼做、什麼時候用和注意事項。

    匯入體組成資料

    從 CSV 或 JSON 檔案匯入體組成測量結果，存入身體記錄。

    在 選單 → 全部工具 → 匯入體組成資料 中選擇檔案。

    這里沒有的器械與今日推薦

    在選單 → 應用程式設定 → 訓練與例行 → 我的器材的這裡沒有的器械中選擇器械後，需要這些器械的動作會從替換動作、計劃生成和今日推薦中去掉。

    沒有日程的日子，首頁今日卡片會以今日推薦挑選主要部位恢復最好、休息最久的训練計劃，并最多顯示三行原因。

    跑步計算機

    在選單的計算機欄開啟跑步計算機，使用配速 ↔ 成績和成績預測。

    • 配速 ↔ 成績：選擇距離，輸入成績或配速其中之一，即可算出另一項。
    • 成績預測：用一個距離的成績預測其他距離的成績，並顯示出處。可用設為基準成績把它設為配速區間的基準成績。

    跑步模式下它排在計算機欄最前面，槓鈴片和 1RM 計算機排在後面。
