    建立例行訓練

    在 首頁 的 我的例行 區域點選 新增。

    1. 在 首頁 的 我的例行 區域點選 新增。
    2. 選擇 建立空白例行訓練 或 從歷史記錄匯入。
    3. 新增動作和組，然後儲存。

    免費最多可建 3 個例行訓練，PRO 不限。結束訓練時也可以把改動同步到例行訓練。

    編輯、複製、刪除例行訓練

    在例行訓練頁面點例行訓練的 ⋯，會出現 編輯例行訓練、複製例行訓練、刪除例行訓練。

    例行訓練頁面可從 首頁 今日卡片的 ⋯ → 選擇例行訓練 開啟。頁面有 我的例行、熱門與公開、訓練計畫 三個標籤，可在 熱門與公開 中從 FitBoost 推薦 選用。

    刪除例行訓練時，用它安排的日程和提醒也會一併刪除。

    自動加重 PRO

    在編輯例行訓練時開啟 自動加重，上次每組都達到目標次數的動作，下次會自動加重。

    訓練中逐組提示下一組重量的功能，請看訓練中教練建議。

    生成適合我的計畫

    選擇目標、時間和器材，就會生成一週的計畫並存為例行訓練。

    1. 點選 首頁 → 訓練計畫 → 生成適合我的計畫。
    2. 選擇目標、訓練經驗、每週天數、每次時長和器材（健身房、在家啞鈴、徒手）。
    3. 設定有氧、想重點練的部位和想休息的部位，點選 生成。
    4. 檢視預覽並存為例行訓練。

    重量不會預先填入，而是在訓練當天根據記錄決定。免費可在 3 個例行訓練的上限內儲存，換一種組合 和 更換動作重新生成 為 PRO 功能。

    跟練現成計畫

    在 首頁 → 訓練計畫 下方選擇現成的計畫並點選 開始計畫，日程就會加入首頁。

    同一頁面上方有 生成適合我的計畫、教練循環訓練 和 每週混合訓練計畫 的入口。

    自訂動作

    列表裡沒有的動作，用 動作列表 → 新增自訂動作 建立。

    可設定記錄方式（重量與次數、時間等）、主要肌肉，以及是否為單側動作。免費最多 5 個，PRO 不限。

    動作列表與動作指南

    在 選單 → 動作列表 中搜尋 1,690 個動作，開啟後可檢視做法和注意事項。

    每個動作都有 說明、注意事項、技巧、我的記錄與統計，以及 替代動作，點 記錄這個動作 可直接開始記錄。可按名稱搜尋或按部位、器材篩選，常練的動作可以收藏。

    用文件收發训練計劃

    在训練計劃 ⋯ → 分享例行訓練，训練計劃文件會通过分享面板發出。對方點開文件并用 FitBoost 打開即可。

    打開收到的文件時會詢問要匯入這個訓練計畫嗎？，保存後加入我的训練計劃。免費版最多 3 個训練計劃。
