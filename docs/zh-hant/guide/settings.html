設定

單位、語言、主題、休息計時、小工具和鎖定畫面等設定。

    重量和距離單位

    在 選單 → 應用程式設定 → 一般設定 的 重量單位 中選擇公斤或磅。

    槓片計算也會使用所選單位。同一頁面還能更改 距離單位 和 每週開始日。只想讓某個動作用磅記錄，可在訓練中點 ⋯ → 此動作使用磅。

    語言

    在 選單 → 應用程式設定 → 語言 中可選擇韓語、英語、日語、簡體中文和繁體中文。

    選擇 跟隨系統 會跟隨裝置語言。

    外觀與主題

    在 選單 → 應用程式設定 → 外觀 中選擇淺色、深色或 跟隨系統，並在 變更主題 中選擇強調色。

    休息計時設定

    在 選單 → 應用程式設定 → 休息計時設定 中設定預設休息時長、提示音和計時器的行為。

    • 預設休息時長、休息調整幅度、休息提示音
    • 背景計時：離開 App 後計時器繼續執行，結束時提醒你。
    • 自動調整休息時長：根據剛完成那組的強度和動作類型決定下一次休息。你自己設定的休息，以及例行訓練和計畫中的休息保持不變。

    訓練與例行設定

    在 選單 → 應用程式設定 → 訓練與例行 中調整訓練頁面的行為。

    • 我的器材：填寫你的槓鈴桿、槓片和啞鈴。
    • RPE/RIR：選擇用哪種方式記錄每組強度。
    • 訓練中教練建議：開關訓練中的下一組重量建議。
    • 允許重複動作、滑動刪除組、完成最後一組後前往下一動作

    想在訓練中保持螢幕常亮，請開啟 一般設定 的 訓練時螢幕常亮。重量每次增加多少，在 鍵盤設定 的 重量間隔 中設定。

    通知

    在 選單 → 應用程式設定 → 通知設定 中開關 背景計時通知 和 訓練計畫提醒。

    收不到通知時，請在裝置設定中確認已允許 FitBoost 的通知。

    小工具與鎖定畫面

    在 選單 → 應用程式設定 → 小工具與鎖定畫面 中選擇 即時動態 或 主畫面小工具。

    • 免費可使用今日訓練小工具。其他小工具、自訂和鎖定畫面即時動態（Android 為即時通知）屬於 PRO。狀態、恢復和教練計畫小工具屬於 PRO+。
    • 即時動態需要 iOS 16.1 或更高版本。
    • iPhone：長按主畫面，點左上角的編輯 → 加入小工具，找到 FitBoost。
    • Android：長按主畫面，開啟小工具，找到 FitBoost。

    刪除所有記錄

    在 選單 → 應用程式設定 最下方的 刪除所有記錄 中刪除這台裝置上的全部記錄。

    無法撤銷。刪除前請先建立備份檔案。
