紀錄分享與裝飾

把跑步和力量訓練紀錄做成分享卡片，用編輯器調整字體、顏色和照片，並儲存為我的範本。

    本頁內容

    1. 選擇分享卡片
    2. 開啟裝飾編輯器
    3. 字體、顏色與照片
    4. 放到人物後面 PRO
    5. 我的範本與自動產生
    6. 分享與裝飾的免費與付費

    選擇分享卡片

    在跑步結果中點 分享紀錄，從 路線、分段、疊在照片上、貼紙 卡片中選一種，做成限時動態或貼文尺寸。

    1. 在跑步結果頁面點 分享紀錄。過去的跑步可在 記錄 中開啟。
    2. 在上方的標籤列選擇卡片，再選擇 限時動態 9:16 或 貼文 4:5 尺寸和背景色。
    3. 開啟或關閉 顯示路線、顯示平均心率、顯示爬升 等項目。
    4. 點 分享到 Instagram 限時動態 會直接開啟 Instagram 限時動態。要傳到別處或儲存到相簿，請用 用其他應用程式分享。

    貼紙 卡片背景透明，會作為可移動的貼圖放進限時動態。路線只依截掉起點和終點附近及隱私區域後的線繪製，卡片中不含底圖、座標和時刻（含日期）。力量訓練可在 記錄 中開啟紀錄後用 分享訓練摘要，或在 統計 中用 分享紀錄卡片，以同樣方式製作卡片。

    開啟裝飾編輯器

    點跑步或力量訓練分享頁面上方的魔杖按鈕（自訂），即可開啟裝飾編輯器。

    1. 點分享頁面右上角的魔杖按鈕。
    2. 從下方列開啟 貼紙、字體、顏色、照片、圖層、我的範本。
    3. 加入貼圖後用手指拖曳，或調整大小和旋轉。用 新增文字 也可以加文字。
    4. 在 尺寸 中選擇 限時動態 9:16、貼文 4:5 或 正方形，完成後匯出或發到限時動態。

    跑步貼圖有距離、時間、配速、海拔剖面和跑過的路線，力量貼圖有 今日訓練、個人紀錄、三大項總和、比上次增加的訓練量、組、訓練部位 等。坡度修正配速或估算 1RM 走勢這類分析值貼圖，依該值原本所屬的等級開放。卡片上的 App 名稱標示與等級無關，一律會顯示。

    字體、顏色與照片

    即使在同一個貼圖裡，也能為 數字、單位、標籤 分別選擇字體和顏色。照片可以從黑白、模糊調整到亮度、對比。

    • 字體：每個部分的字體、大小、字距、等寬數字。字體中沒有的字會提示 此字體沒有的字元會用預設字體顯示。
    • 顏色：基本 3 色、從照片中取的顏色、取色器、顏色代碼。會顯示對比以判斷文字是否清楚，並建議 加上陰影。
    • 照片：黑白、模糊、亮度、對比度、色溫、底部變暗。
    • 路線：單色，或依 配速、坡度 為線上色。
    • 圖層：復原、重做、上移、下移、隱藏、鎖定、位置與旋轉數值、顯示限時動態遮擋區域。

    共有 22 種字體，全部以 SIL 開源字型授權（OFL）收錄在 App 中。免費可在整個貼圖上使用 3 種基本字體，以及基本 3 色、黑白、模糊和單色路線。每個部分單獨選字體和其餘字體、照片取色、滴管、色碼、復原、圖層、數值、遮擋區域、路線上色，以及亮度、對比、暖色、底部變暗屬於 PRO。

    放到人物後面 PRO

    在 照片 中開啟 放到人物後面，會去背照片中的人物，讓貼圖位於人物後面。照片只在裝置內處理。

    1. 在 疊在照片上 卡片或編輯器中選擇照片作為背景。
    2. 在 照片 中開啟 放到人物後面。

    僅在本機去背照片中的人物，讓貼紙位於人物後方。iPhone 使用裝置內建的視覺功能，Android 使用 App 內建的人物分割模型，因此照片不會傳送到任何地方。人物太小或模糊時會顯示 照片中沒有找到人物。

    我的範本與自動產生

    用 將目前版面存為範本 儲存裝飾好的版面、字體和顏色，下次紀錄的數值會直接填進去（PRO）。

    1. 在編輯器中排好版面後，點 我的範本 中的 將目前版面存為範本。
    2. 下次分享時在 我的範本 中選擇該範本，就會填入新紀錄的數值。
    3. 開啟範本的 完成後自動用此範本產生 開關後，訓練或跑步結束時可從結果頁面的 用我的範本分享 直接開啟（PRO+）。

    我的範本只儲存在本裝置和備份檔案中，不會透過裝置間同步上傳。訂閱結束後，已儲存的範本不會刪除，只是 PRO 功能重新鎖定。

    分享與裝飾的免費與付費

    分享卡片和基本裝飾免費。專業編輯工具屬於 PRO，結束後用我的範本直接產生屬於 PRO+。

    • 免費：跑步與力量分享卡片，貼圖的加入、拖曳、大小與旋轉，3 種基本字體，基本 3 色，黑白與模糊，單色路線，限時動態、貼文與正方形尺寸，匯出和直接發到 Instagram 限時動態。
    • PRO：每個部分的字體、大小、字距與數字寬度，其餘字體，照片取色、滴管與色碼，復原、圖層、數值與限時動態遮擋區域，路線上色，亮度、對比、暖色與底部變暗，放到人物後面，我的範本。
    • PRO+：訓練或跑步結束時用我的範本直接產生分享卡片。

    卡片上的 App 名稱標示在所有等級中都會顯示，沒有去除功能。
