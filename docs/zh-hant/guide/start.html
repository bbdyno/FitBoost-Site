    第一次開啟時

    翻過三頁介紹，填寫個人資料和訓練經驗、目標，就可以開始記錄了。

    1. 翻過介紹頁，在最後一頁點選開始。
    2. 填寫暱稱、性別、出生年份、身高和體重。
    3. 在你主要做哪種運動？中選擇以力量為主、力量與跑步或以跑步為主。它只決定先顯示什麼，力量和跑步的功能都能用，之後可以在主要項目中更改。
    4. 選擇訓練經驗（以跑步為主時為跑步經驗），接著選擇訓練目標。接近主要項目的目標排在前面。
    5. 練過的話，包含力量時填寫預估的深蹲 1RM，包含跑步時填寫最近的跑步成績。不知道可以跳過。主要項目包含力量並選擇 第一次 時，會詢問每週幾次、在哪裡訓練，並按所選目標生成第一個例行。

    這些資訊用於推薦重量和估算消耗的熱量。重量單位（kg 或 lb）跟隨裝置的地區設定，之後可以在設定中更改。

    訓練目標

    選擇訓練目標後，計畫產生、教練、飲食的初始值和組安排推薦都會依目標調整。

    1. 點選 首頁 日期旁的目標標籤，或進入 選單 → 應用程式設定 → 訓練目標。
    2. 從 力量、增肌、減脂、增肌減脂並行、肌肉耐力、混合訓練、體能與健康 中選擇一個。

    更改後的目標從下次訓練開始生效。進行中的訓練和你自己建立的例行保持不變。沒選過目標時，根據紀錄推測的目標會標示 根據紀錄推測。

    主要項目

    主要項目只決定力量和跑步哪個先顯示，不會隱藏任何功能。

    1. 開啟 選單 → 應用程式設定 → 主要項目。它在設定最上方、訓練目標下面。
    2. 選擇以力量為主、力量與跑步或以跑步為主。
    • 首頁：分組的順序和一開始折疊的分組會改變。以力量為主會折疊跑步分組，以跑步為主會折疊力量分組，力量與跑步兩組都展開。沒有今天計畫的日子，最上方的卡片也按主要項目顯示。
    • 統計、教練：第一次開啟時顯示主要項目的分區（力量與跑步為力量），之後開啟上次查看的分區。
    • 選單：力量工具、跑步工具和計算機的順序會改變。
    • 第一次制定每週混合訓練計畫時，作為側重的初始值。

    主要項目和訓練目標是兩回事。目標是你想要什麼（增肌、減脂等），主要項目是你做什麼。1.9.0 及以前的力量模式和跑步模式已經取消。第一次開啟 1.9.1 時，會按你以前用的模式設定一次主要項目，並在首頁顯示一次 力量和跑步現已合併到同一個畫面。先顯示的順序可在設定的主要項目中變更。。

    不需要帳戶

    無需註冊或登入。記錄儲存在這台裝置上。

    暱稱可在 選單 → 帳戶 → 編輯個人資料 中修改。記錄不會傳送到我們的伺服器，為了在裝置丟失時也能保住記錄，請使用裝置間同步或備份檔案。

    畫面結構

    底部的標籤有 首頁、記錄、統計、教練、選單 五個。力量和跑步在一個 App 中一起查看。

    • 首頁：最上方是今天的卡片（今天計畫是跑步日時為今天的跑步，力量或循環訓練日時為今天的訓練），下方緊接著是另一項運動的開始按鈕（開始跑步或開始力量訓練），再往下是力量、跑步、身體分組。力量分組裡有 快速記錄、訓練計畫 和 我的例行。
    • 記錄：按日期查看過去的訓練，並進行編輯或刪除。用全部訓練、僅力量、僅跑步標籤篩選。
    • 統計：在上方選擇力量、跑步、身體分區。力量為本週目標、肌肉恢復、力量平衡和訓練量趨勢，跑步為距離、配速區間和預測成績，身體為體組成、體重和心肺適能。
    • 教練：最上方的公共區有本週計畫、干擾提示和混合賽備賽，下面選擇力量、跑步、身體·營養分區。見教練頁的結構。
    • 選單：應用程式設定、資料轉移與備份、傳送給教練、力量和跑步工具、計算機和健康 App 連線。

    分組的順序和一開始折疊哪些分組由主要項目決定。點分組標題折疊或展開後會記住，折疊的一行也顯示本週數值。有進行中的訓練或跑步時，最上方的卡片會變成繼續進行，沒有另一項運動的開始按鈕。在 iPad 和展開的 iPhone Duo 上為兩欄：左側是每項都帶即時數值的選單，右側一開始是恢復地圖，在選單中選擇後右側顯示該內容。
