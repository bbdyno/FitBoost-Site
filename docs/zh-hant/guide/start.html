使用指南

入門

安裝後要做的事、訓練目標和主要項目，以及五個分頁的畫面結構。

    本頁內容

    1. 第一次開啟時
    2. 訓練目標
    3. 主要項目
    4. 不需要帳戶
    5. 畫面結構

    第一次開啟時

    翻過三頁介紹，再一頁一頁選好個人資訊、主要項目和經驗、訓練目標，就可以開始記錄了。主要項目包含力量時還多一頁。

    1. 翻過三頁介紹，在最後一頁點選 開始使用。
    2. 在 請告訴我們你的資料 一頁一次填好暱稱、性別、出生年份、身高和體重。出生年份、身高和體重點選各自那一行來選擇。
    3. 在你主要做哪種運動？中選擇以力量為主、力量與跑步或以跑步為主，並在同一頁下方選擇訓練經驗（以跑步為主時為跑步經驗）。主要項目包含跑步且練過的話，還可以在它下面填寫最近的跑步成績，沒有就留空。主要項目只決定先顯示什麼，力量和跑步的功能都能用，之後可以在主要項目中更改。
    4. 選擇訓練目標。接近主要項目的目標排在前面，列表上方會顯示所選目標的預設值（計畫目標、計畫有氧、飲食）。以跑步為主到這裡結束。
    5. 主要項目包含力量時還多一頁。選了 第一次 的人選擇在哪裡訓練和每週幾次（在健身房時還要選 這裡沒有的器械），並得到依所選目標產生的第一個例行。練過的人填寫預估的深蹲 1RM，不知道就點選 不確定 或 用舉過的重量估算。

    每個問題頁都可以用左上角的 返回 按鈕回到上一頁修改，已選的值會保留。在最後一頁點選 開始使用 即完成。這些資訊用於推薦重量和估算消耗的熱量。重量單位（kg 或 lb）跟隨裝置的地區設定，之後可以在設定中更改。

    訓練目標

    選擇訓練目標後，計畫產生、教練、飲食的初始值和組安排推薦都會依目標調整。

    1. 點選 今天 最下方的 本週 一行，在開啟的畫面最上方點選訓練目標一行，或進入 我的 → 應用程式設定 → 訓練目標。
    2. 從 力量、增肌、減脂、增肌減脂並行、肌肉耐力、力量與耐力、體能與健康 中選擇一個。

    更改後的目標從下次訓練開始生效。進行中的訓練和你自己建立的例行保持不變。沒選過目標時，根據紀錄推測的目標會標示 根據紀錄推測。

    主要項目

    主要項目只決定力量和跑步哪個先顯示，不會隱藏任何功能。

    1. 開啟 我的 → 應用程式設定 → 主要項目。它在設定最上方、訓練目標下面。
    2. 選擇以力量為主、力量與跑步或以跑步為主。
    • 今天：沒有今天計畫的日子，最上方顯示的內容依主要項目決定（以跑步為主為跑步，其餘為力量）。本週畫面中分組的順序和一開始折疊的分組也會改變。以力量為主會折疊跑步分組，以跑步為主會折疊力量分組，力量與跑步兩組都展開。
    • 計畫：構成本週計畫的內容中力量和跑步的順序會改變。記錄 → 分析第一次開啟時顯示主要項目的分區（力量與跑步為力量），之後開啟上次查看的分區。
    • 我的：力量工具、跑步工具和計算機的順序會改變。
    • 第一次制定每週計畫時，作為側重的初始值。

    主要項目和訓練目標是兩回事。目標是你想要什麼（增肌、減脂等），主要項目是你做什麼。1.9.0 及以前的力量模式和跑步模式已經取消。第一次開啟 1.9.1 時，會按你以前用的模式設定一次主要項目，並在 今天 顯示一次 力量和跑步現在不分模式一起使用。先顯示的順序可在設定的主要項目中變更。。

    不需要帳戶

    無需註冊或登入。記錄儲存在這台裝置上。

    暱稱可在 我的 → 帳戶 → 編輯個人資料 中修改。記錄不會傳送到我們的伺服器，為了在裝置丟失時也能保住記錄，請使用裝置間同步或備份檔案。

    畫面結構

    底部的標籤有 今天、計畫、比賽、記錄、我的 五個。2.0.0 把首頁、紀錄、統計、教練、選單改成了這樣：統計移到 記錄 的 分析 欄，教練、訓練計畫和例行移到 計畫，選單移到 我的。

    • 今天：最上方大大地顯示今天要做的一件事。力量日是肌肉恢復地圖，跑步日是訓練結構條，比賽練習日是分段線，用它下面的按鈕開始。緊接著的五個快捷入口（力量、跑步、循環訓練、比賽練習、快速記錄）可以直接開始其他訓練。點選最下方的 本週 一行，會開啟有力量、跑步、身體分組的畫面。休息日會顯示 今天休息 和恢復地圖，快捷入口照常保留。
    • 計畫：有本週每天要做的訓練和 構成本週計畫的內容。備賽、力量教練、訓練計畫、我的例行、動作評估、教練循環訓練、跑步教練、姿勢分析、配速區間 都從這裡開啟。見計畫頁與教練畫面。
    • 比賽：選擇混合賽形式或自己建立，進行逐段計時的練習並查看比賽成績分析。見備賽與練習。
    • 記錄：在上方選擇 記錄 和 分析 欄。記錄 欄是日曆和過去的訓練列表，用全部訓練、僅力量、僅跑步標籤篩選。日曆的每一天會立起項目顏色的柱子（力量為桃色，跑步為天藍色，比賽為主題色），越高表示那天練得越久。分析 欄就是以前的統計，可選擇力量、跑步、身體分區。見分析欄能看到什麼。
    • 我的：最上方是把今年每週做的訓練依項目顏色疊起來的條和 FitBoost PRO 一行，下面是力量工具、跑步工具、健康 App 連線、資料轉移與備份、傳送給教練 和 計算機。應用程式設定 是右上角的齒輪按鈕。

    本週畫面中分組的順序和一開始折疊哪些分組由主要項目決定。點分組標題折疊或展開後會記住，折疊的一行也顯示本週數值。有進行中的訓練或跑步時，今天最上方會變成繼續進行，快捷入口中不屬於正在進行項目的格子會變淡，點選了會告訴你原因。升級到 2.0.0 後第一次開啟時，今天會顯示一次 底部標籤已改為今天、計畫、比賽、記錄、我的。統計在記錄標籤的分析中，教練在計畫標籤中。。在 iPad 和展開的 iPhone Duo 上為兩欄：左側是每項都帶即時數值的選單，右側一開始是恢復地圖，在選單中選擇後右側顯示該內容。
