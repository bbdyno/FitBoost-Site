    第一次開啟時

    翻過三頁介紹，填寫個人資料和訓練經驗、目標，就可以開始記錄了。

    1. 翻過介紹頁，在最後一頁點選開始。
    2. 填寫暱稱、性別、出生年份、身高和體重。
    3. 選擇做重量訓練的時間，接著選擇訓練目標。
    4. 練過的話，填寫預估的深蹲 1RM。不知道的話，可以選擇不確定。選擇 第一次 時，會詢問每週幾次、在哪裡訓練，並依所選目標產生第一個例行。

    這些資訊用於推薦重量和估算消耗的熱量。重量單位（kg 或 lb）跟隨裝置的地區設定，之後可以在設定中更改。

    訓練目標

    選擇訓練目標後，計畫產生、教練、飲食的初始值和組安排推薦都會依目標調整。

    1. 點選 首頁 日期旁的目標標籤，或進入 選單 → 應用程式設定 → 訓練目標。
    2. 從 力量、增肌、減脂、增肌減脂並行、肌肉耐力、混合訓練、體能與健康 中選擇一個。

    更改後的目標從下次訓練開始生效。進行中的訓練和你自己建立的例行保持不變。沒選過目標時，根據紀錄推測的目標會標示 根據紀錄推測。

    不需要帳戶

    無需註冊或登入。記錄儲存在這台裝置上。

    暱稱可在 選單 → 帳戶 → 編輯個人資料 中修改。記錄不會傳送到我們的伺服器，為了在裝置丟失時也能保住記錄，請使用裝置間同步或備份檔案。

    介面結構

    底部的標籤有 首頁、記錄、統計、教練、選單 五個。

    • 首頁：今天的訓練、快速記錄、訓練計畫 和 我的例行。
    • 記錄：按日期檢視過去的訓練，並進行編輯或刪除。
    • 統計：本週目標、肌肉恢復、力量平衡和訓練量趨勢。
    • 教練：PRO+ 的週期計畫和按狀態調整的指導。沒有 PRO+ 時只顯示介紹。
    • 選單：應用程式設定、資料轉移與備份、傳送給教練、計算機和健康 App 連線。

    用 首頁 頂部右側的啞鈴和跑者按鈕，在力量模式和跑步模式之間切換。跑步模式下五個標籤都會以跑步為主。
