    訓練中的下一組重量建議 PRO

    完成一組並記錄強度後，會據此告訴你下一組的重量，以及今天何時該停。

    建議可在 選單 → 應用程式設定 → 訓練與例行 → 訓練中教練建議 中開關。免費使用者每次訓練會看到一次試用提示。PRO+ 還會根據頂組強度當場調整遞減組重量，並預先填好熱身組。

    建議僅供訓練參考，不是醫療建議。如有疼痛，請減輕重量並用 這裡痛 記錄。

    教練循環訓練

    選擇時長、器材和強度，就會安排當天的循環訓練。免費每週 3 次，PRO 不限。

    1. 點選 首頁 → 訓練計畫 → 教練循環訓練。也可以在今日卡片的 ⋯ → 讓教練安排循環訓練 開啟。
    2. 第一次選擇時長、器材和強度並點選 產生循環訓練。之後會按上次的條件直接顯示預覽。
    3. 在預覽中選擇 重新安排、儲存為訓練計畫 或 循環訓練設定（語音提示、音效），然後點選 開始。

    結束後會詢問感受，並據此調整下一次循環訓練。也可以直接在手錶上開始。

    每週混合訓練計畫 PRO+

    把力量、循環訓練和有氧組合成一週日程，並配合你訓練的日子和時間較充裕的日子。

    1. 點選 首頁 → 訓練計畫 → 每週混合訓練計畫。
    2. 選擇星期、目標、側重、有氧、器材和年齡，點選 產生計畫。
    3. 今天的訓練會顯示在 首頁。

    錯過的日子可以用 移動 挪到別的日子，也可以撤銷。

    重心選擇 跑步為主 後，就會成為跑步模式 教練 最上方的每週跑步計畫，並把練下肢後隔天的品質課改為輕鬆跑。見與力量訓練連動的處方。

    教練頁的週期計畫 PRO+

    根據目標、比賽日期和當前 1RM 制定數週的計畫，並決定每次訓練的重量。

    1. 點選 教練 → 制定計畫。
    2. 選擇目標（健力、力量、力量健美、增肌）、每週天數、經驗、推進方式、體重和比賽日期（可選）。
    3. 填寫當前 1RM。不知道的話可以用重量和次數計算。
    4. 點選 制定計畫，今天的訓練會顯示在教練頁和首頁。

    教練頁為 PRO+ 專屬，沒有 PRO+ 時只顯示介紹和 了解 PRO+。

    狀態檢查 PRO+

    訓練前記錄睡眠、肌肉狀態、壓力和精力，會據此調整當天的重量和組數。

    在教練頁的 狀態 卡片點選 記錄，選完後點選 儲存並套用。有計畫時也可以從首頁的 狀態 開啟。連線健康 App後還會用到睡眠時長、HRV 和靜息心率。

    減量與比賽試舉重量 PRO+

    根據成績和疲勞的變化，在教練頁建議減量或延長當前週期。

    當近期成績下滑、練得比計畫更吃力、狀態持續偏低，或距上次減量已過 6 週時，會建議減量。計畫進入賽前幾週（巔峰期、減量期）時，還會顯示第一、二、三次試舉的重量。

    營養目標 PRO+

    根據體重趨勢，每週重新調整熱量以及碳水、蛋白質、脂肪目標。

    在教練頁的 營養目標 卡片中填寫體重、身高、年齡、活動量和目標，點選 設定目標。體重趨勢需要在兩週以上記錄至少 4 次才會顯示。只想算一次的話，請用巨量營養素計算機。

    混合賽備賽

    像正式比賽一样練習混合健身賽：跑 1 公里再做一個項目，重復 8 次，每段單獨計時。免費版每週 3 次。

    1. 打開首頁 → 訓練計畫 → 混合賽備賽。
    2. 選擇組别(重量)、練習范围(完整、一半、只練項目、項目後跑)和目標完賽時間，即可看到每段的量、重量和目標。
    3. 點開始實戰練習，每完成一段就點大按鈕。也可以在手錶上完成。
    4. 結束後會顯示分段錶和丟時間最多的段，點儲存並結束保存。

    設定比賽日期後，會把剩餘週數分為基礎、專項、實戰、調整并告诉你現在該做什麼，第一週測試會找出最弱的項目。比賽結束後填寫正式成績进行對比。此練習功能與任何賽事主辦方无關，分段目標是公開成績的參考值。
