記録は、ためておくだけのものではありません。FitBoostは積み重ねた記録から、今日の重量と休憩時間、やめどきを決めます。

01ワークアウト中のコーチPRO

セットが終わるたびに、次の重量を合わせ直します。

  1. 強度を記録すると

    セットを終えて、あと何回できたかを選ぶと、次のセットの重量がすぐに変わります。

  2. 休憩時間も一緒に

    直前のセットがきつかったほど、休憩が長くなります。終わったら通知で呼びます。

  3. やめどきを知らせます

    疲労で回数が落ち始めたら、今日はここまでと知らせます。使うほど、自分の記録からその基準を学びます。
