ワークアウトの記録

ワークアウトを始めてセットを記録し、終える方法と、過去の記録の直し方です。

    ワークアウトを始める

    ホームの今日のカードで開始をタップします。ルーティンがなければ空のワークアウトで始まり、自由に記録できます。

    1. ホームの今日のカードで開始をタップします。
    2. 別のルーティンにするには、カードの⋯からルーティンを選択を選びます。
    3. 種目を追加してセットを記録します。

    ホーム → マイルーティンからルーティンをすぐ始めたり、記録 → 記録を追加 → ワークアウト開始から始めたりもできます。

    セットを記録する

    重量と回数を入力し、セットの行のチェックをタップするとそのセットが完了します。

    • まとめて完了するには全セット完了をタップします。
    • セット番号をタップすると、そのセットの詳細を編集する画面が開きます。セットタイプ（ウォームアップ・ドロップ・限界など）、グリップ、強度、そのセットだけの休憩時間を決めます。
    • ドロップ・バックオフセットを入れたり、残りのセットをまとめて組んだりするにはドロップ・バックオフとセット構成をご覧ください。

    ドロップ・バックオフとセット構成

    種目カードの構成をタップすると、残りのセットを同じ重量・トップセット＋バックオフ・最後にドロップのいずれかで組み、セットごとの重量と回数を先におすすめします。

    1. 種目カードの構成をタップします。
    2. 構成とセット数・回数・余力を選ぶと、セットごとのおすすめ重量が変わります。
    3. おすすめ通りに入れるをタップするか、行をタップして重量・回数を直してから入れます。
    • ドロップやバックオフだけを付けるには、種目カード⋯のドロップセットを追加・バックオフセットを追加、セット編集画面のこのセットの後にドロップを使います。
    • ドロップの前のセットを終えると休まずにすぐドロップへ進み、最後のドロップの後に休みます。ウォッチでも同じです。
    • 最初に選ばれる構成はトレーニング目標に従います。たとえば筋力は大きな種目でトップセット＋バックオフ、筋肥大はドロップに向くマシン・ケーブル・単関節種目で最後にドロップを選びます。
    • 根拠をタップすると、重量の計算に使った研究とコーチングの方法を見られます。

    セットの強度を記録する

    セットを終えると、完了ボタンの上にこのセットはどうでしたか？と4つのチップが1行で出ます。選ぶと次の重量計算に反映され、押さなければ強度なしで進みます。

    聞き方はメニュー → アプリ設定 → ワークアウト設定 → セットの強度を聞くで完了ボタンの上に1行・ポップアップ・聞かないから選びます。聞かない設定にするとウォッチも聞きません。数値で残すにはセットをタップしてRIRかRPEを入れます。

    休憩タイマー

    セットを終えると休憩タイマーが動きます。10秒ずつ増減したり、一時停止やスキップができます。

    デフォルトの休憩時間、通知音、画面を消しても動くタイマーなどは、タイマー内の休憩タイマー設定か設定で決めます。

    種目ごとのメニュー

    種目名の横の⋯をタップすると、その種目だけを変えるメニューが開きます。

    • 種目を差し替え：同じ部位の別の種目に替えます。
    • スーパーセット設定：別の種目と組んで交互に行います。
    • ここが痛い：痛む部位を記録すると、その部位を使う種目で重量を下げるか別の種目に替えるよう案内します。どのプランでも使えます。
    • この種目はポンドで：その種目だけポンドで記録します。
    • メモ、種目を削除もここにあります。

    ワークアウトを終える

    下のワークアウト完了をタップしたときに記録が保存されます。

    1. ワークアウト完了をタップします。
    2. チェックしていないセットがあれば、完了として記録かチェックしたものだけ記録を選びます。
    3. ルーティンから始めた場合は、変えた構成をルーティンにも反映するか選びます。
    4. まとめ画面でボリューム・時間・使った筋肉を確認し、評価とワークアウトのメモを残します。

    上のメニューの保存せずに終了は保存せずに破棄するボタンです。ワークアウトを終了しますか？現在の記録は保存されません。と表示されたらキャンセルしてワークアウト完了をタップしてください。

    済んだワークアウトを記録する

    ホームのクイック記録か、記録 → 記録を追加 → 済んだワークアウトを記録で、過去のワークアウトを日付と一緒に入力します。

    同じメニューの予定を追加で、これからのワークアウトを予定に入れることもできます。進行中のワークアウトがあるとクイック記録は開かないので、先にそちらを終えてください。

    有酸素は時間や距離を直すと、計算機を押さなくても消費カロリーを推定してすぐ入れます。自分で入れたカロリーとヘルスケアから取り込んだ値はそのままで、体重の記録がなければ推定せずにお知らせします。

    過去の記録を編集・削除する

    記録で記録の⋯をタップすると、編集や削除ができます。

    • ワークアウトを編集：種目とセットを直します。直した内容は統計と次の重量の計算にすぐ反映されます。
    • 日付・時間・メモを編集：日付を移したりメモを変えたりします。
    • この記録で開始：同じ構成で今日もう一度行います。
    • 削除：削除した記録は元に戻せません。

    体重と写真の記録

    記録の身体タブで、身体記録を追加から体重・体脂肪率・骨格筋量を記録します。

    体の写真はフォトタブの写真を追加で残します。記録した体重は、筋力バランスの体重比レベル、有酸素カロリー計算、栄養目標に使われます。体組成の測定結果はファイルから読み込むこともできます。

    メモ

    ワークアウト中は種目の⋯ → メモ、終わったあとはまとめ画面のワークアウトのメモに残します。

    フォームのように何度も見るメモは、種目一覧で種目を開いて種目メモを追加で残してください。写真や動画を添付し、上に固定できます。すべてのメモはメニュー → メモ一覧でまとめて見られます。

    筋トレの音声ガイド

    オンにすると、休憩の残り10秒と終了時に次のセットの重量・回数を読み上げ、自己ベストも知らせます。

    メニュー → アプリ設定 → 筋トレの音声ガイドでオンにします。初めて休憩するとき完了ボタンの上にオンにする1行も出ます。アプリを開いているときだけ話し、裏にあるときは通知で知らせます。ウォッチは10秒前に短く振動します。
