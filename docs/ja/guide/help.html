困ったとき

ウォッチ連携、同期、バックアップ、サブスクリプションで困ったときの確認事項です。

    このページの内容

    1. ウォッチがつながらないとき
    2. Garminがつながらないとき
    3. 同期できないとき
    4. バックアップファイルが開けないとき
    5. 契約したのにPROにならないとき
    6. さっきのワークアウトが記録にないとき
    7. 進行中のワークアウトがあると言われたとき
    8. ヘルスケアとつながらないとき
    9. 通知やロック画面が表示されないとき

    ウォッチがつながらないとき

    メニュー → アプリ設定 → スマートウォッチ設定のウォッチの接続状態に表示される文言で原因を探します。

    • ペアリングされたウォッチがありません。：スマホとウォッチがペアリングされているか、ウォッチのアプリ（WatchアプリやGalaxy Wearable）で確認してください。
    • ウォッチにFitBoostをインストールしてください。：Apple WatchかGalaxy WatchにFitBoostをインストールしてください。
    • ウォッチの接続を待機中：ウォッチでFitBoostを一度開いてください。
    • この端末ではウォッチに対応していません。：このスマホではウォッチを使えません。

    スマートウォッチ連携がオンになっているかも確認してください。ワークアウトをウォッチに送るには、スマホで先にワークアウトを始める必要があります。

    Garminがつながらないとき

    Garminウォッチを接続をタップしたときに表示される文言に従います。

    • 先にGarmin Connectアプリをインストールしてください。：スマホにGarmin Connectアプリをインストールしてウォッチをつなぎます。
    • Garmin Connectアプリでウォッチを選んでください。：Garmin Connectアプリが開いたら、FitBoostで使うウォッチを選びます。
    • ウォッチにFitBoostをインストールしてください。タップするとConnect IQストアが開きます。

    ウォッチでFitBoostを開いてもワークアウトが来ないときは、スマホで先にワークアウトを始めたか確認してください。詳しい手順はGarminウォッチをつなぐにあります。

    同期できないとき

    メニュー → アプリ設定 → デバイス間の同期に表示される文言を確認します。

    • iCloudにサインインしていません。設定アプリでAppleアカウントにサインインしてください
    • Googleドライブへのアクセスが必要です。「今すぐ同期」をタップして再度許可してください
    • iCloudストレージがいっぱいです / Googleアカウントのストレージがいっぱいです：空き容量を増やしてください。
    • 別の端末が新しいバージョンのアプリで保存しました。アプリをアップデートしてください
    • 接続できないため、しばらくしてから再試行します

    2台が同じiCloudまたはGoogleアカウントか、両方で同期をオンにしているか確認してください。iPhoneとAndroidのあいだは同期されません。バックアップファイルで移してください。

    バックアップファイルが開けないとき

    読み込みに失敗しても、この端末の記録はそのままです。表示された文言を確認してください。

    • FitBoostのバックアップファイルではありません。：.fitboostファイルか確認してください。
    • より新しいバージョンのアプリで作成されたファイルです。アプリをアップデートしてから読み込んでください。
    • ファイルが破損しているため読み込みませんでした。この端末の記録はそのままです。：ファイルをもう一度受け取ってみてください。
    • パスワードが正しくありません。：作成時にかけたパスワードを入れる必要があります。忘れたパスワードは調べられません。
    • 会員ファイルではありません。自分のバックアップは「データの移行・バックアップ」から読み込んでください。

    契約したのにPROにならないとき

    FitBoost PRO画面で購入を復元をタップしてください。

    決済したAppleまたはGoogleのアカウントでログインしている必要があります。iPhoneで買ったサブスクリプションはAndroidで、Androidで買ったものはiPhoneで復元できません。詳しくは購入の復元を見てください。

    さっきのワークアウトが記録にないとき

    保存せずに終了で終えたワークアウトは保存されません。記録はワークアウト完了をタップしたときに残ります。

    消えたワークアウトは記録 → 記録を追加 → 済んだワークアウトを記録で入れ直せます。Garminウォッチで行ったワークアウトなら、スマホを近くに置いてウォッチのアプリから送り直してください。

    進行中のワークアウトがあると言われたとき

    進行中のワークアウトを先に完了してください。と表示されたら、開いたままのワークアウトがあります。

    ホームの今日のカードのワークアウト再開で戻ってワークアウト完了をタップするか、不要なら保存せずに終了で破棄してから始め直してください。

    ヘルスケアとつながらないとき

    ヘルスデータの接続に失敗しました。と表示されたら、端末のヘルスケアの権限を確認します。

    iPhoneは設定 → プライバシーとセキュリティ → ヘルスケア → FitBoostで、AndroidはHealth Connectのアプリの権限でFitBoostが許可されているか確認してください。新しく取り込む記録はありません。は、直近30日に新しく取り込むワークアウトがないという意味です。

    通知やロック画面が表示されないとき

    通知がオフになっています。設定でオンにしてください。と表示されたら、端末の設定でFitBoostの通知を許可してください。

    ライブアクティビティがオフのときは、アプリが設定 › FitBoost でライブアクティビティをオンにしてくださいと案内します。通知も許可されている必要があります。ウィジェットとロック画面も見てください。

    前へ設定

    解決しない場合は della.kimko@gmail.com までご連絡ください。機種とアプリのバージョンを添えていただくと早く確認できます。
