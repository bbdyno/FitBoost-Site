記録の共有とカスタマイズ

ラン・筋トレの記録を共有カードにし、編集画面でフォント・色・写真を整え、マイテンプレートに保存する方法です。

    このページの内容

    1. 共有カードを選ぶ
    2. カスタマイズを開く
    3. フォント・色・写真
    4. 人物の後ろに回す PRO
    5. マイテンプレートと自動作成
    6. 共有とカスタマイズの無料と有料

    共有カードを選ぶ

    ランの結果の記録をシェアをタップし、ルート・スプリット・写真に重ねる・ステッカーのカードから選んで、ストーリーズかフィードの大きさで作ります。

    1. ランの結果画面で記録をシェアをタップします。過去のランは記録から開きます。
    2. 上のチップの列でカードを選び、ストーリーズ 9:16・フィード 4:5の大きさと背景色を選びます。
    3. ルートを入れる、平均心拍を入れる、上りを入れるなどの項目をオン・オフします。
    4. Instagramのストーリーズに投稿をタップするとInstagramのストーリーズがすぐ開きます。ほかに送ったり写真に保存したりするにはほかのアプリで共有を使います。

    ステッカーのカードは背景が透明なので、ストーリーズで動かせるステッカーとして入ります。ルートはスタート・ゴール付近と非公開エリアを切り取った線だけで描き、カードには背景の地図・座標・時刻は入りません（日付は入ります）。筋トレは、記録で開いた記録のワークアウト要約を共有や統計の記録カードを共有から同じようにカードを作ります。

    カスタマイズを開く

    ラン・筋トレの共有画面の上にある魔法の杖のボタン（カスタマイズ）をタップすると、編集画面が開きます。

    1. 共有画面の右上にある魔法の杖のボタンをタップします。
    2. 下の欄からステッカー、フォント、色、写真、レイヤー、マイテンプレートを開きます。
    3. ステッカーを入れ、指でドラッグして動かしたり、大きさ・回転を変えたりします。テキストを追加で文字も入れられます。
    4. サイズでストーリーズ 9:16・フィード 4:5・正方形を選び、できたら書き出すかストーリーズに投稿します。

    ランのステッカーには距離・時間・ペース、高度の断面、走ったルートがあり、筋トレのステッカーには今日のワークアウト、自己ベスト、BIG3合計、前回より増えたボリューム、セット、使った筋肉などがあります。勾配補正ペースや推定1RMの推移のような分析値のステッカーは、その値がもともと属するプランに従います。カードのアプリ名の表示は、プランに関係なく必ず入ります。

    フォント・色・写真

    ひとつのステッカーの中でも、数字・単位・ラベルの欄ごとにフォントと色を別々に選べます。写真はモノクロ・ぼかしから明るさ・コントラストまで調整できます。

    • フォント：欄ごとのフォント、サイズ、字間、数字の幅をそろえる。フォントにない文字はこのフォントにない文字は標準フォントで表示しますと知らせます。
    • 色：基本の3色、写真から取った色、スポイト、カラーコード。文字が読みやすいかコントラストを示し、影を付けるをおすすめします。
    • 写真：モノクロ、ぼかし、明るさ、コントラスト、暖かさ、下を暗く。
    • ルート：単色、またはペース・勾配で線に色を付けます。
    • レイヤー：元に戻す・やり直す、前面へ・背面へ、非表示、ロック、位置・回転の数値、ストーリーの隠れる範囲を表示。

    フォントは22種類で、すべてSILオープンフォントライセンス（OFL）のフォントとしてアプリに入っています。無料では基本フォント3つをステッカー全体に使い、基本の3色、モノクロ・ぼかし、単色のルートを使えます。欄ごとのフォントと残りのフォント、写真の色・スポイト・カラーコード、元に戻す・レイヤー・数値・隠れる範囲、ルートの色付け、明るさ・コントラスト・暖かさ・下を暗くはPROです。

    人物の後ろに回す PRO

    写真の人物の後ろに置くをオンにすると、写真の人物を切り抜いてステッカーが人物の後ろに回ります。写真は端末の中だけで処理します。

    1. 写真に重ねるのカードか編集画面で、写真を背景に選びます。
    2. 写真で人物の後ろに置くをオンにします。

    写真の人物を端末内だけで切り抜き、ステッカーを人物の後ろに置きます。iPhoneは端末に入っているビジョンの機能を、Androidはアプリに入っている人物分離モデルを使うので、写真はどこにも送られません。人物が小さかったりぼやけていたりすると写真に人物が見つかりませんでしたと表示されます。

    マイテンプレートと自動作成

    飾った配置・フォント・色を今の配置をテンプレートに保存で保存しておくと、次の記録の値ですぐに埋まります（PRO）。

    1. 編集画面で配置を終えたら、マイテンプレートの今の配置をテンプレートに保存をタップします。
    2. 次に共有するとき、マイテンプレートでそのテンプレートを選ぶと新しい記録の値が入ります。
    3. テンプレートの終了後このテンプレートで自動作成スイッチをオンにすると、ワークアウトやランが終わったあと、結果画面のテンプレートですぐ共有からすぐ開きます（PRO+）。

    マイテンプレートはこの端末とバックアップファイルにだけ保存し、デバイス間の同期では上げません。サブスクリプションが終わっても保存したテンプレートは消えず、PROの機能だけが再びロックされます。

    共有とカスタマイズの無料と有料

    共有カードと基本のカスタマイズは無料です。プロ向けの編集ツールはPRO、終わったらマイテンプレートですぐ作るのはPRO+です。

    • 無料：ラン・筋トレの共有カード、ステッカーの追加・ドラッグ・大きさ・回転、基本フォント3つ、基本の3色、モノクロ・ぼかし、単色のルート、ストーリーズ・フィード・正方形、書き出しとInstagramのストーリーズへの直接投稿。
    • PRO：欄ごとのフォント・大きさ・字間・数字の幅、残りのフォント、写真から取った色・スポイト・カラーコード、元に戻す・レイヤー・数値・ストーリーズの隠れる範囲、ルートの色付け、明るさ・コントラスト・暖かさ・下を暗く、人物の後ろに回す、マイテンプレート。
    • PRO+：ワークアウトやランが終わったら、マイテンプレートで共有カードをすぐ作る。

    カードのアプリ名の表示はどのプランでも入り、消す機能はありません。
