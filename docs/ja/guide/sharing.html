記録の共有とカスタマイズ

ラン・筋トレの記録を共有カードにし、テンプレートやステッカーで飾ってフォント・色・写真を整え、写真やマイテンプレートに保存する方法です。

    共有カードを選ぶ

    ランの結果や運動のまとめのすぐ下にある記録を飾ってシェアをタップすると、共有画面が開きます。上のチップの列でルート・スプリット・写真に重ねる・ステッカーのカードを選び、ストーリーズかフィードの大きさで作ります。

    1. ランを終えた結果画面や、筋トレを終えたまとめ画面で記録を飾ってシェアをタップします。過去の記録も記録から開くと同じボタンがあります。
    2. 上のチップの列でカードを選び、ストーリーズ 9:16・フィード 4:5の大きさと背景色を選びます。チップの列の先頭のカスタムはカスタマイズを開きます。
    3. ルートを入れる、平均心拍を入れる、上りを入れるなどの項目をオン・オフします。
    4. Instagramのストーリーズに投稿をタップするとInstagramのストーリーズがすぐ開きます。ほかに送ったり写真に保存したりするにはほかのアプリで共有を使います。

    ステッカーのカードは背景が透明なので、ストーリーズで動かせるステッカーとして入ります。ルートはスタート・ゴール付近と非公開エリアを切り取った線だけで描き、カードには背景の地図・座標・時刻は入りません（日付は入ります）。筋トレは、まとめ画面の記録を飾ってシェアや上のワークアウト要約を共有、統計の記録カードを共有から同じようにカードを作ります。

    カスタマイズを開く

    共有画面のチップの列の先頭にあるカスタムをタップすると、全画面のカスタマイズが開きます。インスタのストーリーのように、キャンバスの上で直接ドラッグし、書き、消します。

    1. 記録を飾ってシェアで共有画面を開き、チップの列の先頭のカスタムをタップします。
    2. 右側のツールの列からテキスト、ステッカー、テンプレート、写真、レイヤーを選びます。テキストをタップすると、キャンバスの上で直接文字を書けます。
    3. ステッカーは指でドラッグして動かし、2本指で大きさ・回転を変えます。ドラッグ中に下に出るゴミ箱に置くと消えます。
    4. 選んだステッカーをもう一度タップすると色が変わります。文字の入ったステッカーは、もう一度タップすると文字を直せます。
    5. できたら、いちばん下の列から写真に保存するか、Instagramのストーリーズに投稿・ほかのアプリで共有で送ります。

    ステッカーを選ぶと、下に色の列とフォント・影・削除・⋯のボタンが出ます。ゴミ箱に置いて消したステッカーは、上の元に戻す（PRO）でドラッグ前の位置に戻ります。ランのルートは、PROならもう一度タップすると単色・ペース・勾配の色分けを順に切り替えます。キャンバスのサイズ（ストーリーズ 9:16・フィード 4:5・正方形）はレイヤーで選びます。初めて開くと、ドラッグ・ゴミ箱・右側のツールを知らせる吹き出しが一度だけ出ます。折りたたみのiPhoneの内側の画面やiPadを横向きにすると、キャンバスが左、ツールの欄が右に並びます。

    テンプレートですぐ作る

    編集画面の右側のツールの列にあるテンプレートで用意されたテンプレートをタップすると、今の記録の値で埋まった配置がすぐに入ります。無料です。

    1. 編集画面を開き、右側のツールの列のテンプレートをタップします。
    2. テンプレート・この記録で埋まりますの列で、今の記録の値で埋まったプレビューを見てひとつタップします。
    3. ステッカーをドラッグして整えたり、さらに重ねたりします。別のテンプレートをタップして配置だけ変えることもできます。

    用意されたテンプレートはラン用が17種類、筋トレ用が9種類です。タップすると配置だけが変わり、キャンバスの大きさ・背景・写真はそのまま残ります。心拍のないランの心拍・ケイデンスのように、その記録にない値が主役のテンプレートは表示されません。その下のマイテンプレートには、自分で保存したテンプレートが並びます。マイテンプレートと自動作成をご覧ください。

    ステッカーの種類

    ステッカーの欄は記録・テキスト・ワード・デコ・写真のまとまりに分かれています。どの項目もこの記録の値で描いたプレビューで表示されるので、貼る形のまま選べます。

    • 記録：ランは距離・時間・ペース、高度プロフィール、ルートに加えて、ケイデンス、スタート時刻、今週の距離、今月の距離、今月のカレンダー、連続ラン日数。筋トレは今日のワークアウト、自己ベスト、BIG3合計、前回より増えたボリューム、セット、使った筋肉、日付、スタート時刻など。
    • テキスト：テキストを追加、吹き出し、位置ピン。吹き出しは選んでからしっぽの向きのボタンでしっぽを4方向に回します。
    • ワード：ロング走、ネガティブスプリット、脚の日のようなワードチップ。ラン用18個、筋トレ用10個です。
    • デコ：28種類の図形。入れたあとで色を選んだり、線だけに変えたりします。
    • 写真：写真ステッカー（四角、丸くのボタンで丸）と写真グリッド(最大4枚)。

    勾配補正ペースや推定1RMの推移のような分析値のステッカーは、その値がもともと属するプランに従い、ほかのステッカーは無料です。カードのアプリ名の表示は、プランに関係なく必ず入ります。

    長押しメニューと複数選択

    ステッカーを長押しするか、選んでから下の列の⋯（その他）をタップするとメニューが開きます。

    • メニュー：編集（文字のあるステッカー）、複製、最前面へ、最背面へ、影、ロック PRO、複数選択、削除。
    1. ステッカーを長押しして複数選択を選びます。
    2. ほかのステッカーをタップするたびに選択に入れたり外したりします。選んだステッカーをドラッグすると一緒に動きます。
    3. ツールの列のすべて選択、中央揃え、削除でまとめて扱い、完了をタップします。

    ロックを除くメニューと複数選択は無料です。アプリ名の表示は複製も削除もできません。

    写真に保存

    編集画面のいちばん下の左のボタン（写真に保存）をタップすると、仕上げたカードを今の大きさのまま写真に保存します。無料です。

    1. 仕上がったら、編集画面のいちばん下の左のボタンをタップします。
    2. 初めて保存するときに写真へのアクセスを求められます。iPhoneでは写真を追加する許可だけを求めます。
    3. 写真に保存しましたと表示されたら完了です。

    AndroidではFitBoostのアルバムに保存します。アクセスを許可していないと保存できませんでした。設定で写真へのアクセスを確認してください。と表示されるので、端末の設定で写真へのアクセスをオンにします。ほかのアプリに送るには、同じ列のほかのアプリで共有を使います。

    フォント・色・写真

    ひとつのステッカーの中でも、数字・単位・ラベルの欄ごとにフォントと色を別々に選べます。写真はモノクロ・ぼかしから明るさ・コントラストまで調整できます。ステッカーを選ぶと下に出る列のフォントと色の点からすぐ変えられます。

    • フォント：欄ごとのフォント、サイズ、字間、数字の幅をそろえる。フォントにない文字はこのフォントにない文字は標準フォントで表示しますと知らせます。
    • 色：基本の3色、写真から取った色、スポイト、カラーコード。文字が読みやすいかコントラストを示し、影を付けるをおすすめします。
    • 写真：モノクロ、ぼかし、明るさ、コントラスト、暖かさ、下を暗く。
    • ルート：単色、またはペース・勾配で線に色を付けます。
    • レイヤー：元に戻す・やり直す、前面へ・背面へ（無料）、非表示、ロック、位置・回転の数値、ストーリーの隠れる範囲を表示。

    フォントは22種類で、すべてSILオープンフォントライセンス（OFL）のフォントとしてアプリに入っています。無料では基本フォント3つをステッカー全体に使い、基本の3色、モノクロ・ぼかし、単色のルートを使えます。欄ごとのフォントと残りのフォント19種類、写真の色・スポイト・カラーコード、元に戻す、レイヤーの非表示・ロック、数値、隠れる範囲、ルートの色付け、明るさ・コントラスト・暖かさ・下を暗くはPROです。

    人物の後ろに回す PRO

    写真の人物の後ろに置くをオンにすると、写真の人物を切り抜いてステッカーが人物の後ろに回ります。写真は端末の中だけで処理します。

    1. 写真に重ねるのカードか編集画面で、写真を背景に選びます。
    2. 写真で人物の後ろに置くをオンにします。

    写真の人物を端末内だけで切り抜き、ステッカーを人物の後ろに置きます。iPhoneは端末に入っているビジョンの機能を、Androidはアプリに入っている人物分離モデルを使うので、写真はどこにも送られません。人物が小さかったりぼやけていたりすると写真に人物が見つかりませんでしたと表示されます。

    マイテンプレートと自動作成

    飾った配置・フォント・色を今の配置をテンプレートに保存で保存しておくと、次の記録の値ですぐに埋まります（PRO）。

    1. 編集画面で配置を終えたら、テンプレートの欄の下にあるマイテンプレートの今の配置をテンプレートに保存をタップします。
    2. 次に共有するとき、マイテンプレートでそのテンプレートを選ぶと新しい記録の値が入ります。
    3. テンプレートの終了後このテンプレートで自動作成スイッチをオンにすると、ワークアウトやランが終わったあと、結果画面のテンプレートですぐ共有からすぐ開きます（PRO+）。

    マイテンプレートはこの端末とバックアップファイルにだけ保存し、デバイス間の同期では上げません。サブスクリプションが終わっても保存したテンプレートは消えず、PROの機能だけが再びロックされます。

    共有とカスタマイズの無料と有料

    共有カードと、カスタマイズのテンプレート・ステッカー・複数選択・写真に保存は無料です。プロ向けの編集ツールはPRO、終わったらマイテンプレートですぐ作るのはPRO+です。

    • 無料：ラン・筋トレの共有カード、用意されたテンプレート（ラン17・筋トレ9）、記録のステッカー（ケイデンス・スタート時刻・今週の距離・今月の距離・今月のカレンダー・連続ラン日数を含む）、テキスト・吹き出し・位置ピン・ワードチップ・デコ・写真ステッカー・写真グリッド、ドラッグ・大きさ・回転、長押しメニュー（ロックを除く）、複数選択、レイヤーの順序、基本フォント3つ（ステッカー全体）、基本の3色、モノクロ・ぼかし、単色のルート、ストーリーズ・フィード・正方形、写真に保存・書き出し・Instagramのストーリーズへの直接投稿。
    • PRO：数字・単位・ラベルの欄ごとのフォント・大きさ・字間・数字の幅、残りのフォント19種類、写真から取った色・スポイト・カラーコード、元に戻す、レイヤーの非表示・ロック、数値、ストーリーズの隠れる範囲、ルートの色付け（ペース・勾配）、明るさ・コントラスト・暖かさ・下を暗く、人物の後ろに回す、マイテンプレート。
    • PRO+：ワークアウトやランが終わったら、マイテンプレートで共有カードをすぐ作る。

    分析値のステッカーは、その値がもともと属するプランに従います。カードのアプリ名の表示はどのプランでも入り、消す機能はありません。
