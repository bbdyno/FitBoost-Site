ルーティンとプログラム

    ルーティンを作る

    ホームのマイルーティン欄で追加をタップします。

    1. ホームのマイルーティン欄で追加をタップします。
    2. 空のルーティンを作成か過去の記録から取り込むを選びます。
    3. 種目とセットを入れて保存します。

    無料ではルーティンを3つまで作れ、PROは無制限です。ワークアウトを終えるときに、変えた構成をルーティンに反映することもできます。

    ルーティンの編集・複製・削除

    ルーティン画面でルーティンの⋯をタップすると、ルーティンを編集、ルーティンを複製、ルーティンを削除が表示されます。

    ルーティン画面はホームの今日のカードの⋯ → ルーティンを選択で開きます。マイルーティン、人気・公開、ワークアウト予定の3つのタブがあり、人気・公開ではFitBoostのおすすめから選んで使えます。

    ルーティンを削除すると、そのルーティンで入れた予定と通知も一緒に削除されます。

    重量を自動で上げる PRO

    ルーティン編集で重量を自動で上げるをオンにすると、前回すべてのセットで目標回数をこなした種目は、次回の重量を上げておきます。

    ワークアウト中にセットごとに次の重量を案内する機能は、ワークアウト中のコーチを見てください。

    自分に合うプログラムを作る

    目標・スケジュール・器具を選ぶと、1週間のプログラムを組んでルーティンとして保存します。

    1. ホーム → プログラム → 自分に合うプログラムを作るをタップします。
    2. 目標、トレーニング経験・週の日数・1回の時間、器具（ジム・自宅のダンベル・自重）を選びます。
    3. 有酸素、もっと鍛えたい部位、休ませる部位を決めて作成をタップします。
    4. プレビューを確認してルーティンとして保存します。

    重量は前もって入れず、トレーニング当日の記録を見て決めます。無料はルーティン3つの上限内で保存でき、別の構成を見ると種目を変えて作り直すはPROです。

    用意されたプログラムに取り組む

    ホーム → プログラムの下のほうから用意されたプログラムを選んでプログラムを開始をタップすると、予定がホームに入ります。

    同じ画面の上には自分に合うプログラムを作る、コーチサーキット、週間ハイブリッドプランの入口があります。

    自分の種目

    一覧にない種目は種目一覧 → 自分の種目を追加で作ります。

    記録方法（重量・回数、時間など）、主働筋、片側ずつ行う種目かどうかを決めます。無料は5つまで、PROは無制限です。

    種目一覧と実施ガイド

    メニュー → 種目一覧で1,690種目を探し、種目を開いて説明と注意点を見ます。

    種目の画面には説明、注意点、コツ、自分の記録と統計、代替種目があり、この種目を記録するからすぐ記録を始められます。名前で探したり部位・器具で絞り込んだりでき、よく行う種目はお気に入りに入れておけます。

    ルーティンをファイルでやり取りする

    ルーティンの⋯→ルーティンを共有で、ルーティンファイルが共有シートから送られます。受け取った人はファイルをタップしてFitBoostで開きます。

    受け取ったファイルを開くとルーティンを取り込みますか？と聞かれ、保存するとマイルーティンに加わります。無料プランはルーティン3件までです。
