    プランタブとコーチ画面

    プランには、今週の日ごとのワークアウトとこのプランを作るもののチップがあります。2.0.0でコーチタブはなくなり、筋トレコーチ・ランニングコーチのチップからコーチ画面を開きます。

    • いちばん上の帯：大会の日付を決めてあると、大会までの12週間を基礎・特化・実戦・調整の段階で描いた帯が表示されます。大会準備がなく週間プランがあるときは、今週の曜日ごとに種目の色の棒を立てた帯が表示されます。
    • 今週 PRO+：月曜から日曜まで、日ごとにその日やること（コーチのセッション・ルーティン・サーキット・ラン）と、終えた日・できなかった日を表示し、予定のない曜日は休養日です。行をタップするとプランの画面が開きます。PRO+でなければ週間プランを作るのロックされた行です。週間プランをご覧ください。
    • 筋トレと並行して走るとき：最近の筋トレとランの両方があるときに出ます。筋トレと連動した処方をご覧ください。
    • 大会準備のチップ：大会に移動します。大会の準備と練習をご覧ください。
    • 筋トレのチップ：筋トレコーチ（ブロックプラン、ディロード、コンディションチェック。動作評価の行だけが無料で、ほかはPRO+）、プログラム、マイルーティン、動作評価、コーチサーキット。
    • ランニングのチップ：ランニングコーチ（ランニングコーチ、無料）、フォーム分析、ペースゾーン。
    • コーチ画面のからだ・栄養セクション：心肺フィットネス（無料）、栄養目標・体組成コーチング・ストレスと回復（PRO+）。コーチ画面の上にあるセクションの切り替えから開きます。

    チップの筋トレ・ランニングの順番はメイン種目に従います。コーチ画面はタップしたチップのセクションで開き、上のセクションの切り替えの並びはいつも筋トレ・ランニング・からだ・栄養の順です。

    ワークアウト中の次の重量の提案 PRO

    セットを終えて強度を記録すると、その結果から次のセットの重量と、今日やめるタイミングを案内します。

    提案はマイ → アプリ設定 → ワークアウト設定 → ワークアウト中のコーチでオン・オフします。無料ではワークアウト1回につき1度だけお試しの案内が出ます。PRO+ではトップセットの強度からバックオフセットの重量をその場で調整し、ウォームアップセットもあらかじめ入れます。

    提案はトレーニングの参考値で、医療上の助言ではありません。痛みがあれば重量を下げ、ここが痛いで記録してください。

    コーチサーキット

    時間・器具・強度を選ぶと、その日のサーキットを組みます。無料は週3回、PROは無制限です。

    1. 今日のショートカットにあるサーキットをタップします。プランのコーチサーキットのチップや、今日の開始の横の⋯ → コーチにサーキットを組んでもらうからも開けます。
    2. 初回は時間・器具・強度を選んでサーキットを作るをタップします。次からは前回の条件ですぐプレビューが出ます。
    3. プレビューで組み直す、ルーティンとして保存、サーキット設定（音声案内・効果音）を選び、開始をタップします。

    終わるとどうだったかを聞き、答えに合わせて次のサーキットを調整します。ウォッチからすぐ始めることもできます。

    週間プラン PRO+

    筋トレ・サーキット・ランを組み合わせて1週間の予定を組みます。プランはひとつで、直すと今日の今日のワークアウトとプランの今週の一覧にすぐ反映されます。

    1. プランで週間プランを作るの行をタップします。プランがあるときは今週の一覧の行をタップします。プラン → プログラム → 週間プランや、今日 → 今週画面のランニンググループにある週間プランのショートカットからも開けます。
    2. 曜日、目標、重点、有酸素、器具、年齢を選んでプランを作るをタップします。重点の最初の値はメイン種目に従います。
    3. 今日のワークアウトが今日のいちばん上に表示されます。プランの画面では、その日の欄の開始から始めます。

    条件を変えるときは作り直すをタップします。プランの1週間は、設定の週の開始曜日にかかわらず月曜から日曜までです。自分で直したルーティンや予定に入れたルーティンは上書きせずに残します。できなかった日は別の日に移さず、そのまま残します。筋トレ・サーキットの日をできなかった週の翌週は、プランのルーティンの重量・回数を上げずに前回のままにします。ブロックプランがあればプランの筋トレの日にコーチのセッションが順に置かれ、心肺フィットネスのブロックを進めていればそのセッションも有酸素の日に置かれます。

    重点でランニング中心を選ぶとランの日が多いプランになり、下半身トレーニングの翌日のポイント練習をイージーランに変えます。ランニングコーチと筋トレと連動した処方をご覧ください。

    筋トレコーチのブロックプログラム PRO+

    目標と大会日、今の1RMから数週間のプログラムを組み、毎回のワークアウトの重量を決めます。

    1. プラン → 筋トレコーチ → プログラムを作るをタップします。
    2. 目標（パワーリフティング・筋力・パワービルディング・筋肥大）、週の日数、経験、進め方、体重、大会日（任意）を選びます。
    3. 今の1RMを入力します。わからなければ重量と回数から計算できます。
    4. プログラムを作るをタップすると、今日のワークアウトがコーチ画面と今日に表示されます。

    筋トレセクションのブロックプランはPRO+専用のため、PRO+でない場合は動作評価の行と紹介、PRO+を見るだけが表示されます。週間プランがあるときは筋トレの日をコーチのプログラムで組むの行から作り、コーチのセッションがプランの筋トレの日に順に置かれます。

    コンディションチェック PRO+

    トレーニング前に睡眠・筋肉の状態・ストレス・エネルギーを記録すると、その日の重量とセットを調整します。

    プランの筋トレコーチ・ランニングコーチから開いたコーチ画面のコンディションカードでチェックをタップし、すべて選んだら保存して反映をタップします。プログラムがある場合は今日のコンディション欄からも開けます。ヘルスケアやGarmin Connectと連携すると、睡眠時間・HRV・安静時心拍も使います。

    ディロードと大会の試技重量 PRO+

    記録と疲労の推移を見て、筋トレコーチの画面でディロードやブロックの延長を提案します。

    最近の記録が落ちている、処方よりきつくこなしている、コンディションが低い状態が続いている、前回のディロードから6週が過ぎた、といった場合にディロードを勧めます。プログラムが大会直前の週（ピーキング・テーパー）に入ると、第1・第2・第3試技の重量も表示します。

    栄養目標 PRO+

    体組成や体重の推移を見て、毎週カロリーと炭水化物・たんぱく質・脂質の目標を合わせ直します。

    プランから開いたコーチ画面のからだ・栄養セクションにある栄養目標カードで体重・身長・年齢・活動量・目標を入力し、目標を決めるをタップします。直近30日以内の体組成（除脂肪量）があれば、体重の代わりに除脂肪量で維持カロリーとたんぱく質を計算し、目標体脂肪率を入れると目標体重を表示します（体組成の反映）。体重の推移は2週間以上で4回以上記録すると表示されます。1回だけ計算するならマクロ計算機を使ってください。

    大会の準備と練習

    大会で、準備している大会の区間ごとに時間を計りながら本番のように練習し、記録を残します。練習は無料で週3回までです。

    1. 大会を開きます。いちばん上にいま準備している大会が表示され、別の大会に変えるには大会を変えるをタップします（大会を選ぶ・自分で作る）。
    2. レース練習をタップして準備画面を開きます。今日のショートカットにあるレース練習も同じ画面を開きます。
    3. 部門(重量)、練習の範囲、完走目標(レース全体)を選ぶと、区間ごとの量・重量・目標が区間ラインで表示されます。種目の前の移動時間を別に計るにはトランジションを別に計測をオンにします。ダブルス・リレーはチーム分担をご覧ください。
    4. 本番練習を始めるをタップし、区間を終えるたびに下の大きなボタンを押します。ウォッチで終えても大丈夫です。
    5. 終わると区間表と最も遅れた区間が出ます。記録を保存して終えるで保存します。

    練習中はいまの区間の時間がいちばん大きく表示され、その下に目標までの残り時間と、終えた区間・いまの区間・次の区間を描いた区間ラインがあります。重量や距離で競う区間は制限時間がカウントダウンされ、次へ進むときに挙げた重量や進んだ距離を聞きます。あとで入力をタップすると、区間表の入力からあとで入力できます。制限時間を過ぎても自動では進まず、知らせるだけです。

    目標は用意された時間から選ぶか、直接入力で時・分・秒を入れます（5分〜5時間）。入れた目標で区間目標と、ランのペース・種目の合計・トランジションの時間が出し直されます。いちばん速い全体練習か初週の診断から見た予想より2%を超えて速い目標なら、無理かもしれないと知らせます。区間の予想は実際の大会で測った研究値とコーチング現場の方法論に従い、研究がない部分は現場推定と分けて書きます。出典は計算の根拠で見られます。完走者の分布データがない大会では、目標を区間に分けたり予想を作り上げたりせずに過去の自分の練習と比べ、時間だけで競わない大会には完走タイムの目標がありません。

    準備画面の大会の日付を選ぶで大会の日付を選ぶと、残りの週を基礎・特化・実戦・調整に分けて今やることを示し、大会とプランに大会までの残り日数といまの段階が表示されます。分布データがある大会では、初週の診断で弱い種目も見つけます。特定の大会とは関係のない練習機能で、距離・回数・重量は公開されているルールに従い、公式資料で確認できなかった値は未確認と表示されます。

    スマホで始めた練習は、Apple Watch・Galaxy Watch・Garminウォッチで、今の区間名、量と目標、その区間にかかった時間、手首の心拍を見ながら計測できます。区間の終わりはApple Watch・Galaxy Watchでは区間終了、Garminではスタートボタンです。ラン区間の距離はスマホの位置で測ります。重量・距離を入力する区間は、ウォッチで進めると値なしで終わるので、スマホの区間表で入力します。

    大会を選ぶ・自分で作る

    大会の大会を変えるをタップすると、大会を選ぶの画面でハイブリッド大会の形式11種類から選ぶか、自分で作るで自分の大会を作れます。

    1. 大会のいちばん上、大会名の横にある大会を変えるをタップします。
    2. 形式ごとに、一般的な名前、区間の数、区間の順番を描いた小さな帯、確認の状態（確認済み・一部未確認）が表示されます。ひとつタップすると、部門ごとの区間が区間ラインで表示されます。
    3. この大会で準備するをタップするとその大会が自分の大会になり、練習と結果の入力、週間プランの大会練習の日がその区間の順番に従います。

    自分で作るでは大会名を入力し、ランを追加と種目を追加で区間を順に並べてから保存するをタップします。種目は名前と量（メートル・回数・カロリー）、重量を入力します。ランのない大会、ランの距離が違う大会、重量や距離で競う大会も同じ画面で練習します。大会を選ぶの画面と大会の下のほうにあるランニング大会の行は、マラソンやハーフのようなランニング大会用で、ランの開始画面をレースを選んだ状態で開きます（PRO）。大会名は各主催者の商標で、FitBoostはどの大会とも提携・協賛関係のない独立したアプリです。

    大会結果の入力と分析

    大会の結果を入力で大会の完走タイムと区間タイムを入力すると、大会分析でどこで時間を失ったかを確認できます。

    1. 大会で結果を入力をタップします。
    2. 完走タイムを入力し、わかる範囲で区間タイムを、選んだ大会の区間の順番どおりに入力します。わからない欄は空けたままでかまいません。
    3. 保存して分析を見るをタップします。

    分析は、ひとことの判定、完走タイム、区間の帯、時間を多く失った区間、区間ごとの差、次の目標の順です。完走者の分布データがある大会では、同じ部門の完走者と比べたパーセンタイルを表示し、目標にするで次の目標を大会の目標にします。分布データがない大会では、パーセンタイルと次の目標を作り上げずに、同じ大会の過去の自分の結果と比べます。区間タイムがなければ完走タイムだけで見ます。結果サイトが対応している大会は、結果リンクから読むに自分の結果のURLを貼り付けて、その1件だけを読み込みます。入力した結果と過去の練習は大会の過去の大会・練習にたまり、タップするともう一度開けます。

    ダブルス・リレー部門とチーム分担

    ダブルス・リレー(4人)の部門を選ぶとルールの要点が表示され、チームメンバーの診断から、誰が何をどれだけ担当するかをチーム分担カードが決めます。

    1. 大会のレース練習から開いた準備画面でダブルスかリレー(4人)をタップし、部門（女子・男子・ミックスなど）を選びます。
    2. チーム分担カードでメンバーをタップし、チームメイトの診断（1kmラン・ローイング・ファーマーズキャリー・ウォールボール）を入力します。自分の診断は大会の日付を決めたあと、上の大会準備カードで入力します。
    3. チームの予想と種目ごとの分担、一緒に走るペースや担当する区間を見ます。
    • ダブルス：1kmは2人で一緒に走り、一緒に走るペースは1人で走ると遅いほうに合わせます。種目の分担は働く時間が同じになるよう速い人が多く受け持ち、エルゴ250m・スレッド12.5mのような交代の単位も表示します。ミックスダブルスは2人とも男子オープンの重量です。
    • リレー：4人がそれぞれ1kmとその後の種目を2回ずつ受け持ち、予想の合計がいちばん小さくなるよう各自が得意な種目のある区間を担当します。ミックスリレーは女子2人・男子2人で、それぞれ自分の性別の重量を扱います。

    診断のないメンバーは一般的な記録で計算します。ダブルスの練習では区間名に2人の分担が、リレーでは担当する走者の名前が付き、ウォッチにもそのまま送られます。交代の単位のうち研究がないもの（ウォールボール10回など）には現場推定と付きます。
