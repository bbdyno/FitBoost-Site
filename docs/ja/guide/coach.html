    ワークアウト中の次の重量の提案 PRO

    セットを終えて強度を記録すると、その結果から次のセットの重量と、今日やめるタイミングを案内します。

    提案はメニュー → アプリ設定 → ワークアウト設定 → ワークアウト中のコーチでオン・オフします。無料ではワークアウト1回につき1度だけお試しの案内が出ます。PRO+ではトップセットの強度からバックオフセットの重量をその場で調整し、ウォームアップセットもあらかじめ入れます。

    提案はトレーニングの参考値で、医療上の助言ではありません。痛みがあれば重量を下げ、ここが痛いで記録してください。

    コーチサーキット

    時間・器具・強度を選ぶと、その日のサーキットを組みます。無料は週3回、PROは無制限です。

    1. ホーム → プログラム → コーチサーキットをタップします。今日のカードの⋯ → コーチにサーキットを組んでもらうからも開けます。
    2. 初回は時間・器具・強度を選んでサーキットを作るをタップします。次からは前回の条件ですぐプレビューが出ます。
    3. プレビューで組み直す、ルーティンとして保存、サーキット設定（音声案内・効果音）を選び、開始をタップします。

    終わるとどうだったかを聞き、答えに合わせて次のサーキットを調整します。ウォッチからすぐ始めることもできます。

    週間ハイブリッドプラン PRO+

    筋トレ・サーキット・有酸素を組み合わせて1週間の予定を組みます。トレーニングする曜日と時間に余裕のある曜日に合わせます。

    1. ホーム → プログラム → 週間ハイブリッドプランをタップします。
    2. 曜日、目標、重点、有酸素、器具、年齢を選んでプランを作るをタップします。
    3. 今日のワークアウトがホームに表示されます。

    できなかった日は移すで別の日に移せ、元に戻すこともできます。

    重点でランニング中心を選ぶと、ランニングモードのコーチのいちばん上にある週間ランプランになり、下半身トレーニングの翌日のポイント練習をイージーランに変えます。筋トレと連動した処方をご覧ください。

    コーチタブのブロックプログラム PRO+

    目標と大会日、今の1RMから数週間のプログラムを組み、毎回のワークアウトの重量を決めます。

    1. コーチ → プログラムを作るをタップします。
    2. 目標（パワーリフティング・筋力・パワービルディング・筋肥大）、週の日数、経験、進め方、体重、大会日（任意）を選びます。
    3. 今の1RMを入力します。わからなければ重量と回数から計算できます。
    4. プログラムを作るをタップすると、今日のワークアウトがコーチタブとホームに表示されます。

    コーチタブはPRO+専用のため、PRO+でない場合は紹介とPRO+を見るだけが表示されます。

    コンディションチェック PRO+

    トレーニング前に睡眠・筋肉の状態・ストレス・エネルギーを記録すると、その日の重量とセットを調整します。

    コーチタブのコンディションカードでチェックをタップし、すべて選んだら保存して反映をタップします。プログラムがある場合はホームのコンディション欄からも開けます。ヘルスケアと連携すると、睡眠時間・HRV・安静時心拍も使います。

    ディロードと大会の試技重量 PRO+

    記録と疲労の推移を見て、コーチタブでディロードやブロックの延長を提案します。

    最近の記録が落ちている、処方よりきつくこなしている、コンディションが低い状態が続いている、前回のディロードから6週が過ぎた、といった場合にディロードを勧めます。プログラムが大会直前の週（ピーキング・テーパー）に入ると、第1・第2・第3試技の重量も表示します。

    栄養目標 PRO+

    体重の推移を見て、毎週カロリーと炭水化物・たんぱく質・脂質の目標を合わせ直します。

    コーチタブの栄養目標カードで体重・身長・年齢・活動量・目標を入力し、目標を決めるをタップします。体重の推移は2週間以上で4回以上記録すると表示されます。1回だけ計算するならマクロ計算機を使ってください。

    ハイブリッドレース準備

    1kmラン→種目を8回つなぐハイブリッドフィットネスレースを本番のように練習し、区間ごとに記録します。無料プランは週3回です。

    1. ホーム → プログラム → ハイブリッドレース準備を開きます。
    2. 部門(重量)、練習の範囲(全部・半分・種目だけ・種目後のラン)、完走目標を選ぶと区間ごとの量・重量・目標が見えます。
    3. 本番練習を始めるを押し、区間を終えるたびに大きなボタンを押します。ウォッチで終えても大丈夫です。
    4. 終わると区間表と最も遅れた区間が出ます。記録を保存して終えるで保存します。

    大会の日付を決めると残りの週を基礎・強化・実戦・調整に分けて今やることを示し、初週の診断で弱い種目を見つけます。大会後は公式記録を入れて比べます。特定の大会とは関係のない練習機能で、区間目標は公開結果をまとめた参考値です。
