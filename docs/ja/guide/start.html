    初めて開いたら

    紹介画面を3枚めくり、プロフィールとトレーニング経験・目標を入力すればすぐに記録できます。

    1. 紹介画面をめくり、最後の画面で開始をタップします。
    2. ニックネーム、性別、生まれ年、身長と体重を入力します。
    3. 筋トレの経験を選び、続けてトレーニング目標を選びます。
    4. 経験がある方はスクワットの推定1RMを入力します。わからない場合は、わからないという選択肢を選べます。初めてですを選ぶと、週何回・どこでトレーニングするかを聞いて、目標に合わせた最初のルーティンを作ります。

    入力した情報はおすすめ重量と消費カロリーの計算に使います。重量単位（kg・lb）は端末の地域設定で決まり、あとから設定で変更できます。

    トレーニング目標

    トレーニング目標を選ぶと、プログラム作成・コーチ・食事の初期値とセット構成のおすすめが目標に合わせて決まります。

    1. ホームの日付の横にある目標チップをタップするか、メニュー → アプリ設定 → トレーニング目標を開きます。
    2. 筋力·筋肥大·減量·リコンプ·筋持久力·ハイブリッド·体力・健康から1つ選びます。

    変えた目標は次のトレーニングから反映されます。進行中のトレーニングと自分で作ったルーティンはそのままです。目標を選んだことがなければ、記録から推定した目標に記録から推定と表示されます。

    アカウントは不要です

    登録もログインも不要です。記録はこの端末に保存されます。

    ニックネームは メニュー → アカウント → プロフィールを編集 で変更します。記録は当社のサーバーに送られないため、端末をなくしても記録を守れるようデバイス間の同期やバックアップファイルを使ってください。

    画面の構成

    下のタブは ホーム、記録、統計、コーチ、メニュー の5つです。

    • ホーム：今日のワークアウト、クイック記録、プログラム、マイルーティンがあります。
    • 記録：過去のワークアウトを日付ごとに見て、編集や削除をします。
    • 統計：今週の目標、筋肉の回復、筋力バランス、ボリュームの推移を見ます。
    • コーチ：PRO+のブロックプログラムとコンディションに合わせたコーチングです。PRO+でない場合は紹介だけが表示されます。
    • メニュー：アプリ設定、データの移行・バックアップ、トレーナーに送る、計算機、ヘルスケア連携があります。
