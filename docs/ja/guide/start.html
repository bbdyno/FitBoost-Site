はじめに

インストール後にすること、トレーニング目標とメイン種目、5つのタブの画面構成を説明します。

    このページの内容

    1. 初めて開いたら
    2. トレーニング目標
    3. メイン種目
    4. アカウントは不要です
    5. 画面の構成

    初めて開いたら

    紹介画面を3枚めくり、自分の情報、メイン種目と経験、トレーニング目標を1画面ずつ選べばすぐに記録できます。筋トレが入ったメイン種目では、もう1画面あります。

    1. 紹介画面を3枚めくり、最後の画面でFitBoostを始めるをタップします。
    2. あなたのことを教えてくださいの画面で、ニックネーム、性別、生まれ年、身長、体重をまとめて入力します。生まれ年・身長・体重は行をタップして選びます。
    3. 主にどんな運動をしますか？で筋トレ中心・筋トレとランニング・ランニング中心のどれかを選び、同じ画面の下でトレーニングの経験を選びます（ランニング中心ではランの経験）。ランニングが入ったメイン種目で経験がある方は、その下に最近のランの記録も入力でき、なければ空けておきます。メイン種目は先に表示する順番だけを決め、筋トレとランニングの機能はすべて使えます。あとからメイン種目で変えられます。
    4. トレーニング目標を選びます。メイン種目に近い目標が先に並び、一覧の上に選んだ目標の初期値（プログラムの目標・プログラムの有酸素・食事）が表示されます。ランニング中心はここで終わりです。
    5. 筋トレが入ったメイン種目では、もう1画面あります。初めてを選んだ方は、どこでトレーニングするかと週何回行うかを選び（ジムならここにない器具も選びます）、選んだ目標に合わせた最初のルーティンを受け取ります。経験がある方はスクワットの推定1RMを入力し、わからなければわからないか挙げた重さから計算をタップします。

    質問の画面ごとに左上の戻るボタンで前の画面に戻って直すことができ、選んだ値はそのまま残ります。最後の画面でFitBoostを始めるをタップすると完了です。入力した情報はおすすめ重量と消費カロリーの計算に使います。重量単位（kg・lb）は端末の地域設定で決まり、あとから設定で変更できます。

    トレーニング目標

    トレーニング目標を選ぶと、プログラム作成・コーチ・食事の初期値とセット構成のおすすめが目標に合わせて決まります。

    1. 今日のいちばん下の今週の行をタップして開いた画面で、いちばん上のトレーニング目標の行をタップするか、マイ → アプリ設定 → トレーニング目標を開きます。
    2. 筋力·筋肥大·減量·リコンプ·筋持久力·筋力・持久力·体力・健康から1つ選びます。

    変えた目標は次のトレーニングから反映されます。進行中のトレーニングと自分で作ったルーティンはそのままです。目標を選んだことがなければ、記録から推定した目標に記録から推定と表示されます。

    メイン種目

    メイン種目は、筋トレとランニングのどちらを先に表示するかだけを決めます。どの機能も隠しません。

    1. マイ → アプリ設定 → メイン種目を開きます。設定のいちばん上、トレーニング目標の下にあります。
    2. 筋トレ中心、筋トレとランニング、ランニング中心のどれかを選びます。
    • 今日：今日の計画がない日にいちばん上に表示されるものがメイン種目に従います（ランニング中心はラン、ほかは筋トレ）。今週画面のグループの順番と、最初に折りたたむグループも変わります。筋トレ中心はランニングのグループを、ランニング中心は筋トレのグループを折りたたみ、筋トレとランニングは両方を開きます。
    • プラン：このプランを作るものの筋トレ・ランニングの順番が変わります。記録 → 分析は、初めて開くときはメイン種目のセクションが開き（筋トレとランニングは筋トレ）、その後は最後に見たセクションが開きます。
    • マイ：筋トレのツール・ランニングのツール・計算機の順番が変わります。
    • 週間プランを初めて作るとき、重点の最初の値になります。

    メイン種目はトレーニング目標とは別の値です。目標は何を望むか（筋肥大・減量など）、メイン種目は何をするかです。1.9.0まであった筋トレモード・ランニングモードはなくなりました。1.9.1を初めて開くと、使っていたモードに合わせてメイン種目が一度だけ決まり、今日に筋トレとランニングをモードなしで一緒に使えます。先に表示する順番は設定のメイン種目で変えられます。が一度表示されます。

    アカウントは不要です

    登録もログインも不要です。記録はこの端末に保存されます。

    ニックネームは マイ → アカウント → プロフィールを編集 で変更します。記録は当社のサーバーに送られないため、端末をなくしても記録を守れるようデバイス間の同期やバックアップファイルを使ってください。

    画面の構成

    下のタブは 今日、プラン、大会、記録、マイ の5つです。2.0.0でホーム・記録・統計・コーチ・メニューからこのように変わり、統計は記録の分析タブに、コーチ・プログラム・ルーティンはプランに、メニューはマイに移りました。

    • 今日：いちばん上に今日やることがひとつ大きく表示されます。筋トレの日は筋肉の回復マップ、ランの日はワークアウト構成の帯、大会練習の日は区間ラインで、その下のボタンで始めます。すぐ下の5つのショートカット（筋トレ・ランニング・サーキット・レース練習・クイック記録）で、ほかのワークアウトをすぐ始められます。いちばん下の今週の行をタップすると、筋トレ・ランニング・からだのグループがある画面が開きます。休養日には今日は休みましょうと回復マップが表示され、ショートカットはそのままです。
    • プラン：今週の日ごとのワークアウトとこのプランを作るものがあります。大会準備、筋トレコーチ、プログラム、マイルーティン、動作評価、コーチサーキット、ランニングコーチ、フォーム分析、ペースゾーンをここから開きます。プランタブとコーチ画面をご覧ください。
    • 大会：ハイブリッド大会の形式を選ぶか自分で作り、区間ごとに計る練習と大会結果の分析を見ます。大会の準備と練習をご覧ください。
    • 記録：上で記録と分析のタブを切り替えます。記録タブはカレンダーと過去のワークアウトの一覧で、すべての運動・筋トレのみ・ランのみのチップで絞り込みます。カレンダーの日のマスには種目の色の棒（筋トレはピーチ、ランはスカイブルー、大会はテーマカラー）が立ち、高いほど長く行った日です。分析タブは以前の統計で、筋トレ・ランニング・からだのセクションを選びます。分析タブで見られることをご覧ください。
    • マイ：いちばん上に、今年の週ごとのワークアウトを種目の色で積み上げた帯とFitBoost PROの行があり、その下に筋トレ・ランニングのツール、ヘルスケア連携、データの移行・バックアップ、トレーナーに送る、計算機があります。アプリ設定は右上の歯車ボタンです。

    今週画面のグループの順番と最初に折りたたむグループはメイン種目が決めます。グループの見出しをタップして折りたたんだり開いたりするとそのまま記憶し、折りたたんだ行にも今週の数値が表示されます。進行中のワークアウトやランがあると、今日のいちばん上はその再開になり、ショートカットのうち進行中の種目でないものは薄く表示され、タップすると理由を知らせます。2.0.0に更新してから初めて開くと、今日に下のタブが今日・プラン・大会・記録・マイに変わりました。統計は記録タブの分析、コーチはプランタブにあります。が一度表示されます。iPadと開いたiPhone Duoでは、左に項目ごとに数値が付いたメニュー、右に最初は回復マップが表示され、メニューで選ぶとその内容が右に開く2列になります。
