    重量・距離の単位

    メニュー → アプリ設定 → 一般設定の重量単位でキログラムとポンドから選びます。

    プレート計算も選んだ単位で行います。同じ画面で距離単位と週の開始曜日も変えられます。1つの種目だけポンドで記録するには、ワークアウト中に⋯ → この種目はポンドでをタップします。

    言語

    メニュー → アプリ設定 → 言語で、韓国語、英語、日本語、簡体字中国語、繁体字中国語から選びます。

    システム設定を選ぶと端末の言語に合わせます。

    表示モードとテーマ

    メニュー → アプリ設定 → 表示モードでライト・ダーク・端末の設定に合わせるから選び、テーマ変更でアクセントカラーを選びます。

    休憩タイマーの設定

    メニュー → アプリ設定 → 休憩タイマー設定で、デフォルトの休憩時間、通知音、タイマーの動作を決めます。

    • デフォルト休憩時間、休憩時間の調整幅、休憩通知音
    • バックグラウンドタイマー：アプリを離れてもタイマーが動き、終わると知らせます。
    • 休憩時間の自動調整：直前のセットの強度と種目の種類で次の休憩を決めます。自分で決めた休憩と、ルーティン・プランの休憩はそのままにします。

    ワークアウト設定

    メニュー → アプリ設定 → ワークアウト設定で、ワークアウト画面の動作を変えます。

    • マイ器具：手持ちのバー・プレート・ダンベルを入れます。
    • RPE/RIR：セットの強度をどちらで記録するか選びます。
    • ワークアウト中のコーチ：ワークアウト中の次の重量の提案をオン・オフします。
    • 同じ種目の重複を許可、スワイプでセット削除、最終セット後に次の種目へ

    ワークアウト中に画面が消えないようにするには、一般設定の運動中は画面を常にオンをオンにします。重量をいくつずつ上げるかはキーボード設定の重量入力間隔で決めます。

    通知

    メニュー → アプリ設定 → 通知設定でバックグラウンドタイマー通知とワークアウト予定の通知をオン・オフします。

    通知が届かないときは、端末の設定でFitBoostの通知が許可されているか確認してください。

    ウィジェットとロック画面

    メニュー → アプリ設定 → ウィジェット・ロック画面でライブアクティビティとホーム画面ウィジェットを選びます。

    • 無料では今日のワークアウトのウィジェットを使えます。ほかのウィジェットとカスタマイズ、ロック画面のライブアクティビティ（Androidはライブ通知）はPROです。コンディション・回復・コーチプログラムのウィジェットはPRO+です。
    • ライブアクティビティはiOS 16.1以降で使えます。
    • iPhone：ホーム画面を長押しし、左上の編集 → ウィジェットを追加でFitBoostを探します。
    • Android：ホーム画面を長押しし、ウィジェットでFitBoostを探します。

    すべての記録を削除

    メニュー → アプリ設定のいちばん下のすべての記録を削除で、この端末の記録をすべて消します。

    元に戻せません。消す前にバックアップファイルを作っておいてください。
