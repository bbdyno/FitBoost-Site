    プレート計算機

    目標重量を入れると、片側に付けるプレートを案内します。無料です。

    メニューの計算機欄でプレートをタップします。バーの重さと手持ちのプレートはマイ器具に合わせ、計算機内の変更で別の器具を選びます。

    1RMと強度プログラムの計算機

    重量と回数（15回以下）を入れると1RMを推定します。

    1RM計算機でこの重量で強度プログラムを作成をタップすると強度プログラム計算機に進み、その1RMから5×5、5/3/1、8/6/3、GVTのセットごとの重量を計算します。

    有酸素・カロリー・マクロ計算機

    メニューの計算機欄から有酸素、カロリー、マクロの計算機を開きます。

    • 有酸素カロリー計算：ランニングマシンの速度・傾斜やエルゴのペースから消費カロリーを計算します。
    • カロリー計算機：運動強度（MET）と時間、体重から消費カロリーを推定します。
    • マクロ計算機：目標カロリーと炭水化物・たんぱく質・脂質を計算します。

    すべてのツールはメニュー → すべてのツールにまとまっています。

    マイ器具

    バーとプレート、ダンベル・ケトルベルの間隔、マシン1段の重さを入れておくと、プレート計算がその器具に合わせられます。

    メニュー → アプリ設定 → ワークアウト設定 → マイ器具で開きます。無料は1か所だけ登録でき、複数の場所の登録や、おすすめ重量をその器具で作れる重量に合わせる機能はPROです。

    トレーニング用語集

    ドロップセットやRPEのような見慣れない言葉をメニュー → トレーニング用語集で調べられます。

    用語はセット・強度・計画の3つに分かれ、それぞれ何か、どうやるか、いつ使うか、注意点を書いています。

    体組成データの読み込み

    体組成の測定結果をCSVかJSONファイルから読み込み、身体記録に入れます。

    メニュー → すべてのツール → 体組成データを読み込むでファイルを選びます。

    ここにない器具と今日のおすすめ

    メニュー → アプリ設定 → ワークアウト設定 → マイ器具のここにない器具で器具を選ぶと、その器具を使う種目を代わりの種目・プログラム作成・今日のおすすめから外します。

    予定のない日は、ホームの今日のカードが今日のおすすめとして、主に使う部位がよく回復していて長く休んだルーティンを選び、理由を最大3行で示します。

    ランニング計算機

    メニューの計算機の欄からランニング計算機を開き、ペース ↔ タイムとタイム予測を使います。

    • ペース ↔ タイム：距離を選び、タイムかペースのどちらかを入れると、もう一方を計算します。
    • タイム予測：ひとつの距離のタイムからほかの距離のタイムを予測し、出典も表示します。この記録を基準記録にするでペースゾーンの基準記録にできます。

    ランニングモードでは計算機の欄のいちばん前に置かれ、プレート・1RM計算機は後ろに回ります。
