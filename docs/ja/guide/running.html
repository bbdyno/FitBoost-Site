ランニング

ランニングモードに切り替え、スマホやウォッチでランを計測し、ペースゾーンとマイコースを使う方法です。

    ランニングモードに切り替える

    ホームのヘッダー右にある2つのボタンでランナーの側をタップすると、アプリ全体がランニングモードになります。メニューのトレーニングモードの行からも切り替えられます。

    1. ホームのヘッダー右のダンベル・ランナーのボタンでランニングをタップします。
    2. 筋トレに戻すには、同じボタンの筋トレをタップします。
    • ホーム：今日のランのカード、今週の距離と過去8週のバー、マイコース・ペースゾーン・週間プランへのショートカット、最近のラン。
    • 記録：ランのみの表示で開き、すべての運動に切り替えられます。
    • 統計：いちばん上にランの欄が加わり、その下の筋トレの欄はそのままです。
    • コーチ：いちばん上にラン中心の週間プランが置かれます（PRO+）。
    • メニュー：マイコース、ペースゾーン、ラン設定の行が加わります。

    モードが変えるのは画面だけです。記録・処方・ヘルスケアのデータは筋トレとひとつにつながっています。筋トレの予定がある日はホームに今日は筋トレの日です・筋トレモードで見ると表示されます。進行中のワークアウトがあると進行中のトレーニングがあります。終わってから切り替えられます。と表示され、切り替わりません。選んだモードはアプリを開き直しても残ります。

    ランを始める

    ランニングモードのホームで今日のランのカードのランを開始をタップし、ランの種類と計測する機器を選びます。

    1. ホームで今日のランのカードのランを開始をタップします。
    2. いちばん上のカードは今日の処方（なければおすすめ）です。そのままランを開始をタップするか、下からフリーラン・タイムトライアル・コースラン・トラック・トレッドミルなどの種類を選びます。
    3. 計測する機器でスマートフォンかウォッチを選びます。
    4. スマホで初めて屋外を計測するとき、位置情報の許可を求めます。アプリの使用中の位置情報を許可します。

    スマートフォンはスマホの衛星測位で計測し、画面を消してもそのランが終わるまで計測を続けます。トレッドミルは位置情報を使わず歩数で距離を見積もります。タイムトライアルは全力で走ってペースゾーンを決める日です。構成トレーニング（閾値・インターバル・坂のステップ案内）とレース（目標タイムのペースとゴール予想）はPROです。ウォッチで計測する方法はウォッチで走るにあります。

    ラン中の画面と音声ガイド

    ラン中は距離と現在のペースが大きく表示され、その下に勾配補正ペース・心拍・ケイデンス・ラップ・上り・平均ペースの欄が並びます。

    • 上部に計測している機器（スマートフォンで計測中など）と位置情報の状態（GPS検索中など）が表示されます。
    • 目標のあるステップでは目標のバーが範囲内・速すぎ・遅すぎを知らせます。
    • ラップで自分でラップを切り、一時停止・再開・終了を使います。構成トレーニングでは次のステップで次へ進みます。
    • コースを走ると残りの距離と過去の自分より前か後ろかが表示され、外れるとコースを外れましたと知らせます。

    音声ガイドはラップ・ステップ・範囲外・コース外れをイヤホンで伝えます。スマホで計測するときはスマホから流れ、ウォッチで計測するときはウォッチが振動で知らせます。メニュー → ラン設定で音声ガイド、オートポーズ、オートラップ、現在ペースの計算幅を変えます。オートポーズをオンにすると、信号待ちのように立ち止まった時間は数えません。

    結果と指標の根拠

    終えると、走った道の地図、距離・時間・平均ペース・上り、スプリット、分析が表示されます。指標をタップすると式・根拠・限界を見られます。

    • スプリット：区間ごとのペース・心拍・勾配。区間の勾配補正の値はPROです。
    • 分析 PRO：勾配補正ペース、心拍ドリフト、心拍負荷、セッション負荷、ケイデンス、地形。
    • どのくらいきつかったですか？：1〜10から選ぶと、セッション負荷とフィットネス・疲労の計算に入ります。
    • コースとして保存でこの道をコースとして保存し、ファイルに書き出すでGPXファイルをほかのアプリに送ります。

    勾配補正ペースは平地だったらどのくらいかを見積もった値で、下り坂の得を大きく見積もる限界があります。心拍ドリフトは前半と後半の効率を比べるもので、強度が一定の20分を超えるランでだけ計算します。今回の記録が基準記録に使えそうなら基準にするボタンが表示されます。過去のランは記録からタップしてもう一度開きます。

    基準記録とペースゾーン

    最近の記録をひとつ基準記録として入れると、イージー・マラソン・閾値・インターバルのペースと予想タイムが決まります。

    1. メニュー → ペースゾーンを開きます。ランニングモードのホームのペースゾーンショートカットからも開けます。
    2. 記録を入れるをタップし、3km・5km・10km・ハーフ・フルマラソンから距離を選んでタイム（分:秒）を入れます。
    3. 予想タイムと心拍ゾーンの基準（最大心拍または閾値心拍）を確認します。

    ペースはダニエルズとギルバートの酸素コストの式（VDOT）で計算し、このペースの算出方法で式と出典を見られます。記録がなければタイムトライアルで測るか、ランの結果の基準にするをタップします。入れてから8週たつと、もう一度測るようにお知らせします。

    筋トレと連動した処方

    1回のランの距離は、過去30日の最長ランの110%以内をおすすめします。週間ランプランを使うと、下半身トレーニングの翌日のポイント練習をイージーランに変えます。

    • 過去30日の最長ランの110%以内にしました：5,200人を18か月追った観察研究で、この線を超えたランのけがのリスクが高くなっていました。自分で延ばしても止めず、知らせるだけです。いまの上限は統計の1回の距離上限にあります。
    • 昨日の下半身トレーニングのため軽めにしました PRO+：筋損傷の2日後に30分ランのタイムが約4%遅くなったというランダム化試験に従います。変わった日だけ、今日のカードに理由が1行つきます。
    • 基準記録がないか古いため、タイムトライアルをおすすめします：基準記録がないか古い場合は、プランの最初のポイント練習をタイムトライアルに変えます。

    週間ランプランは、ランニングモードのコーチのいちばん上にあるラン中心の週間プランを作るから作ります（PRO+）。筋トレの日と重ならないようにイージーとポイント練習を分け、筋トレの処方はそのままでランの配置だけを動かします。

    マイコースを作る・取り込む

    同じ道を2回走ると自動でコースになります。メニュー → マイコースから、過去のラン・地図への描画・ファイルでも作れます。

    1. メニュー → マイコースを開き、コースを作るをタップします。
    2. 過去のラン、地図に描く、ファイルから選びます。
    3. 名前をつけて保存し、コース画面のこのコースを走るで走ります。

    地図に描くは地図をタップして打った点を直線でつなぎます。地図を使えない版ではこの項目は表示されません。ファイルはGPXとTCXを開けます。コースを走ると過去の自分と競い、コース画面に自己ベストと走った記録がたまります。コースの一部をマイ区間にして、その区間の記録だけを見るのはPROです。

    コースを送る・受け取る

    コース画面のコースを送るから、リンク・QRコード・ファイルのどれかで送ります。サーバーは通りません。

    1. メニュー → マイコースで送るコースを開きます。
    2. コースを送るで送り方を選び、必要なら自分の記録も送るをオンにします。
    3. 受け取った人はリンクをタップするかQRコードを読み取り、表示されるコースを受け取りましたの画面で保存します。

    リンクをスマホのブラウザで開くと、コースの図と距離が表示され、アプリで開くボタンがあります。コピーしたリンクはマイコースの右上の⋯にあるコピーしたリンクを開くでも開けます。送るときはスタート・ゴール付近をランダムに隠し、時刻・心拍は入れません。一緒に送る記録は区間ごとのかかった時間だけで、日付・時刻は含みません。長いコースはリンクに収まらない長さです。ファイルで送ってください。と表示されるので、ファイルで送ります。

    位置を隠す

    コースを送ったりファイルに書き出したりするとき、スタート・ゴール付近をランダムな長さで切り取ります。自宅や職場の周辺は非公開エリアにしておけます。

    1. メニュー → ラン設定を開きます。
    2. 共有時にスタート・ゴールを隠すで隠す距離を選びます。選んだ距離に0〜200mをランダムに足して切り取ります。
    3. 非公開エリアの最近のスタート地点周辺を隠すをタップすると、いちばん最近のランを始めた場所の周辺を隠します。

    隠す円の中心は実際の位置から少しずらして一度だけ決めるので、何度送っても平均を取って場所を割り出しにくくなっています。自分の端末の中の結果の地図と記録は隠さず、そのまま残ります。

    ウォッチで走る

    Apple Watch、Galaxy Watch、Garminウォッチで計測できます。開始画面でウォッチを選び、ウォッチで開始します。

    1. 先にウォッチをつないでおきます。
    2. 開始画面の計測する機器でウォッチを選び、ランを開始をタップします。
    3. スマホにウォッチで開始してくださいと表示されたら、ウォッチのFitBoostで開始します。

    ウォッチはペース範囲・ステップ・コースの線を表示し、範囲を外れると振動で知らせます。Apple Watchは次のステップの5秒前にも振動します。終わると記録がスマホに届きます。Garminウォッチの衛星設定はメニュー → ラン設定 → 衛星設定（Garmin）で選び、最高精度はバッテリーを多く使います。ウォッチには別のモードはなく、スマホで選んだランを表示します。

    ランニングの無料と有料

    計測はすべて無料です。PROは記録を読み解く分析と構成トレーニングを、PRO+は筋トレの回復に合わせた週間ランプランを加えます。

    • 無料：スマホと3種類のウォッチでの計測、リアルタイムのペース・心拍、オートラップとスプリット、基準記録・ペースゾーン・予想タイム、マイコース（同じ道の検出・描画・ファイル・受け取り）、リンク・QRコード・ファイルでの送信、GPXの書き出し、非公開エリア、ヘルスケアへの書き込み、1回の距離上限、指標の根拠。
    • PRO：勾配補正ペース・心拍ドリフト・心拍負荷・セッション負荷・臨界速度、筋トレと合わせたフィットネス・疲労、構成トレーニング（閾値・インターバル・坂のステップ案内）、レース当日モード（目標ペーサー・ゴール予想）、コース内のマイ区間の記録。
    • PRO+：筋トレの回復に合わせたラン中心の週間プラン（下半身トレーニングの翌日を軽めにする調整を含む）。

    ロックされた欄には鍵のマークがつき、タップするとFitBoost PROの画面が開きます。サブスクリプションが終わっても、すでに計測した記録の分析値は消えず、隠れるだけです。ラン中の画面には広告を入れません。
