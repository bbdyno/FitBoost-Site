    無料でできること

    ワークアウトの記録は数の制限なく無料です。ルーティンは3つ、自分の種目は5つまで作れます。

    1,690種目と実施ガイド、3・5・8・10回の推定重量、プレート計算機、回復マップ、デバイス間の同期、バックアップファイル、ヘルスケア連携、ウォッチ、トレーナーに送る機能、今日のワークアウトのウィジェットも無料です。会員の記録は1人、マイ器具は1か所まで持てます。

    ランは計測・コース・送信・書き出しまで無料です。詳しい区分はランニングの無料と有料にあります。

    共有カードと、カスタマイズのテンプレート・ステッカー・複数選択・写真に保存、基本フォント3つ・基本の3色も無料です。共有とカスタマイズの無料と有料をご覧ください。

    PRO

    PROは次に持つ重量を計算します。

    • ルーティンの自動増量、1–15回の個人の回数・重量カーブ、ワークアウト中の次の重量とやめどきの提案
    • 自分の記録から学ぶ強度の補正、筋力バランスの処方、停滞の検知、器具に合わせたおすすめ重量、週間コーチングレポート
    • プログラムの別の構成・作り直し、コーチサーキット無制限、2台の記録の統合
    • ロック画面のライブアクティビティ、ホーム画面ウィジェットとカスタマイズ
    • ルーティン・自分の種目・会員の記録・器具の数の制限なし
    • 広告なし：PROのあいだはすべての広告がオフになります。
    • ランの分析（勾配補正ペース・心拍ドリフト・心拍負荷・セッション負荷・臨界速度、筋トレと合わせたフィットネス・疲労）、構成トレーニング、レース当日モード、コース内のマイ区間の記録
    • 共有カスタマイズのプロ向けツール（欄ごとのフォント、写真の色・スポイト、元に戻す、レイヤーの非表示・ロック、ルートの色付け、写真の補正、人物の後ろに回す、マイテンプレート）

    PRO+

    PROのすべての機能に、コーチタブのプログラムとその日のコンディションに合わせたコーチングを加えます。

    • ブロックピリオダイゼーション、大会の試技重量、ディロードの提案
    • 睡眠・筋肉痛・ストレス・HRVによるその日の強度調整、トップセットの強度によるバックオフ重量の調整
    • 筋肉ごとの週間セット数の調整、体重の推移に合わせて変わる栄養目標
    • ウォームアップセットの自動入力、代替種目の選択、週間ハイブリッドプラン
    • コンディション・回復・コーチプログラムのウィジェット
    • 筋トレの回復に合わせたラン中心の週間プラン
    • ワークアウトやランが終わったら、マイテンプレートで共有カードをすぐ作る

    PROもPRO+も月額または年額のサブスクリプションです。メニュー上部のFitBoost PROバナーをタップすると、価格と比較表が表示されます。

    購入の復元

    メニューのFitBoost PROバナーをタップし、右上の購入を復元をタップします。

    購入したAppleまたはGoogleのアカウントでログインしている必要があります。サブスクリプションは決済したストアのアカウントに結びついているため、iPhoneで契約した場合はAndroidでは復元できません。逆も同じです。

    解約

    決済はAppleまたはGoogleのアカウントで行われるため、解約もそちらで行います。

    1. iPhoneは設定 → ユーザ名 → サブスクリプション、AndroidはPlayストア → プロフィール → お支払いと定期購入 → 定期購入を開きます。
    2. 一覧からFitBoostを選んで解約します。

    PRO+の利用中は、FitBoost PRO画面の右上がサブスクリプションの管理に変わり、すぐに移動できます。更新日の24時間前までに解約しないと自動で更新されることがあります。返金は決済したストアに依頼してください。

    広告を見てPROを試す

    広告を見られるときは、FitBoost PRO画面に広告を見て PRO を試すカードが表示されます。

    短い広告を最後まで見ると、決められた時間だけPROの機能が使えます。最後まで見なかった場合は使えるようになりません。
