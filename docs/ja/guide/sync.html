同期とバックアップ

端末間で記録をそろえ、新しいスマホへ移し、バックアップファイルを作る方法です。

    このページの内容

    1. デバイス間の同期
    2. 同期されないもの
    3. 新しいスマホに移す
    4. バックアップファイルを作る
    5. バックアップファイルを読み込む
    6. 記録をなくさないために

    デバイス間の同期

    同じアカウントの端末どうしで記録を自動でそろえます。iPhone・iPadはiCloud、AndroidはGoogleドライブを使います。無料です。

    1. メニュー → アプリ設定 → デバイス間の同期を開きます。
    2. 同期をオンにします。すぐにそろえるには今すぐ同期をタップします。
    3. ほかの端末でも同じアカウントで同じようにオンにします。

    記録は当社のサーバーを通らず、あなたのiCloudやGoogleドライブにだけ保存されます。

    同期されないもの

    写真・動画ファイル、サブスクリプション、進行中のワークアウトは端末ごとです。

    • 写真・動画ファイルは移しません。メモの文章はそろいます。
    • サブスクリプション、進行中のワークアウト、ヘルスケアとウォッチの連携、選んでいる器具は端末ごとに持ちます。
    • iPhoneとAndroidのようにOSが違う端末どうしは自動でそろえません。バックアップファイルで移してください。

    新しいスマホに移す

    同じOSどうしならデバイス間の同期か端末のバックアップで、iPhoneとAndroidのあいだはバックアップファイルで移します。

    1. 以前のスマホでメニュー → データの移行・バックアップ → バックアップファイルを作成をタップします。
    2. 作ったファイルをメッセンジャー・メール・クラウドなどで新しいスマホに送ります。
    3. 新しいスマホでメニュー → データの移行・バックアップ → バックアップファイルを読み込むからそのファイルを開きます。
    4. 置き換えを選びます。

    同じOSならデバイス間の同期をオンにしておくだけでも移せます。端末のバックアップ（iCloudバックアップ・Googleの自動バックアップ）がオンなら、新しい端末でアプリを復元するときにも一緒に引き継がれます。サブスクリプションはファイルでは移らないので、購入の復元を見てください。

    データの移行・バックアップ画面にiPhoneとAndroidの間で機種変更するときの3ステップ案内があります。

    バックアップファイルを作る

    メニュー → データの移行・バックアップ → バックアップファイルを作成で記録全体を1つのファイルにします。無料です。

    ワークアウトの記録、ルーティン、予定、身体記録、写真、設定が入ります。パスワードをかけられますが、忘れるとファイルを開けなくなるので、別にメモしておいてください。

    バックアップファイルを読み込む

    メニュー → データの移行・バックアップ → バックアップファイルを読み込むで.fitboostファイルを選び、置き換えか統合かを選びます。

    • 置き換え（無料）：この端末の記録を消してファイルの内容に置き換えます。置き換える前の記録は自動でバックアップされ、元に戻せます。
    • 統合（PRO）：今の記録にファイルの内容を加えます。同じ記録はあとから編集したほうが残り、片方で削除した記録は再び現れます。

    記録をなくさないために

    記録はこの端末に保存されるので、アプリを削除すると端末にあった記録も一緒に消えます。

    • デバイス間の同期か端末のバックアップをオンにしてください。
    • ときどきバックアップファイルを作って別に保管してください。
