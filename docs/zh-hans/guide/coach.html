教练与循环训练

    训练中的下一组重量建议 PRO

    完成一组并记录强度后，会据此告诉你下一组的重量，以及今天何时该停。

    建议可在 菜单 → 应用设置 → 训练与例行 → 训练中教练建议 中开关。免费用户每次训练会看到一次试用提示。PRO+ 还会根据顶组强度当场调整递减组重量，并预先填好热身组。

    建议仅供训练参考，不是医疗建议。如有疼痛，请减轻重量并用 这里疼 记录。

    教练循环训练

    选择时长、器械和强度，就会安排当天的循环训练。免费每周 3 次，PRO 不限。

    1. 点击 首页 → 训练计划 → 教练循环训练。也可以在今日卡片的 ⋯ → 让教练安排循环训练 打开。
    2. 第一次选择时长、器械和强度并点击 生成循环训练。之后会按上次的条件直接显示预览。
    3. 在预览中选择 重新安排、保存为训练计划 或 循环训练设置（语音提示、音效），然后点击 开始。

    结束后会询问感受，并据此调整下一次循环训练。也可以直接在手表上开始。

    每周混合训练计划 PRO+

    把力量、循环训练和有氧组合成一周日程，并配合你训练的日子和时间较充裕的日子。

    1. 点击 首页 → 训练计划 → 每周混合训练计划。
    2. 选择星期、目标、侧重、有氧、器械和年龄，点击 生成计划。
    3. 今天的训练会显示在 首页。

    错过的日子可以用 移动 挪到别的日子，也可以撤销。

    重心选择 跑步为主 后，就会成为跑步教练中的 本周跑步计划，并把练下肢后第二天的质量课改为轻松跑。见跑步教练和与力量训练联动的处方。

    教练页的周期计划 PRO+

    根据目标、比赛日期和当前 1RM 制定数周的计划，并决定每次训练的重量。

    1. 点击 教练 → 制定计划。
    2. 选择目标（力量举、力量、力量健美、增肌）、每周天数、经验、推进方式、体重和比赛日期（可选）。
    3. 填写当前 1RM。不知道的话可以用重量和次数计算。
    4. 点击 制定计划，今天的训练会显示在教练页和首页。

    力量模式的教练页为 PRO+ 专属，没有 PRO+ 时只显示介绍和 了解 PRO+。跑步模式下整个页面会变成跑步教练，所以周期计划要在力量模式中查看。

    状态检查 PRO+

    训练前记录睡眠、肌肉状态、压力和精力，会据此调整当天的重量和组数。

    在教练页的 状态 卡片点击 记录，选完后点击 保存并应用。有计划时也可以从首页的 状态 打开。连接健康应用后还会用到睡眠时长、HRV 和静息心率。

    减量与比赛试举重量 PRO+

    根据成绩和疲劳的变化，在教练页建议减量或延长当前周期。

    当近期成绩下滑、练得比计划更吃力、状态持续偏低，或距上次减量已过 6 周时，会建议减量。计划进入赛前几周（巅峰期、减量期）时，还会显示第一、二、三次试举的重量。

    营养目标 PRO+

    根据体重趋势，每周重新调整热量以及碳水、蛋白质、脂肪目标。

    在教练页的 营养目标 卡片中填写体重、身高、年龄、活动量和目标，点击 设定目标。体重趋势需要在两周以上记录至少 4 次才会显示。只想算一次的话，请用宏量计算器。

    混合赛备赛

    像正式比赛一样练习混合健身赛：跑 1 公里再做一个项目，重复 8 次，每段单独计时。免费版每周 3 次。

    1. 打开首页 → 训练计划 → 混合赛备赛。
    2. 选择组别(重量)、练习范围(完整、一半、只练项目、项目后跑)和目标完赛时间，即可看到每段的量、重量和目标。
    3. 点开始实战练习，每完成一段就点大按钮。也可以在手表上完成。
    4. 结束后会显示分段表和丢时间最多的段，点保存并结束保存。

    设定比赛日期后，会把剩余周数分为基础、专项、实战、调整并告诉你现在该做什么，第一周测试会找出最弱的项目。比赛结束后填写正式成绩进行对比。此练习功能与任何赛事主办方无关，分段目标是公开成绩的参考值。
