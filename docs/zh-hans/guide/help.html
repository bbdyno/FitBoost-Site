常见问题排查

手表连接、同步、备份、订阅和跑步定位遇到问题时要检查的事项。

    手表连不上时

    根据 菜单 → 应用设置 → 智能手表设置 中 手表连接状态 显示的文字查找原因。

    • 没有已配对的手表。请在手表的配套应用（Watch 应用或 Galaxy Wearable）中确认手机和手表已配对。
    • 请在手表上安装 FitBoost。请在 Apple Watch 或 Galaxy Watch 上安装 FitBoost。
    • 正在等待手表连接请在手表上打开一次 FitBoost。
    • 此设备不支持手表。这台手机无法使用手表。

    也请确认 智能手表同步 已打开。要把训练发送到手表，需要先在手机上开始训练。

    Garmin 连不上时

    按点击 连接 Garmin 手表 时显示的文字操作。

    • 请先安装 Garmin Connect 应用。在手机上安装 Garmin Connect 应用并连接手表。
    • 请在 Garmin Connect 应用中选择手表。打开 Garmin Connect 应用后，选择要用于 FitBoost 的手表。
    • 请在手表上安装 FitBoost。点按即可打开 Connect IQ 商店。

    在手表上打开 FitBoost 却收不到训练时，请确认是否先在手机上开始了训练。详细步骤见连接 Garmin 手表。

    同步不了时

    查看 菜单 → 应用设置 → 设备间同步 中显示的文字。

    • 尚未登录 iCloud。请在“设置”App 中登录 Apple 账户
    • 需要 Google 云端硬盘权限。请点按“立即同步”重新允许
    • iCloud 储存空间已满 / Google 账号储存空间已满请清理或增加储存空间。
    • 另一台设备使用了更新版本的 App 保存。请更新 App
    • 暂时无法连接，稍后会重试

    请确认两台设备使用同一个 iCloud 或 Google 账户，并且都打开了同步。iPhone 和 Android 之间不会同步，请用备份文件转移。

    备份文件打不开时

    导入失败时，这台设备上的记录保持不变。请查看显示的文字。

    • 这不是 FitBoost 备份文件。请确认是 .fitboost 文件。
    • 此文件由更新版本的应用创建。请更新应用后再导入。
    • 文件已损坏，未导入任何内容。此设备上的记录保持不变。请重新获取文件试试。
    • 密码不正确。需要输入创建时设置的密码。忘记的密码无法找回。
    • 这不是学员文件。自己的备份请在“数据迁移与备份”中导入。

    订阅后 PRO 没显示时

    请在 FitBoost PRO 页面点击 恢复购买。

    需要登录付款时使用的 Apple 或 Google 账户。在 iPhone 上购买的订阅无法在 Android 上恢复，在 Android 上购买的也无法在 iPhone 上恢复。详情见恢复购买。

    刚才的训练不在记录里时

    用 不保存并结束 结束的训练不会保存。只有点击 完成训练 才会留下记录。

    丢失的训练可以用 记录 → 添加训练记录 → 记录已完成的训练 重新录入。如果是在 Garmin 手表上做的训练，请把手机放在附近，从手表应用再发送一次。

    提示有进行中的训练时

    看到 请先完成进行中的训练。 时，说明还有未结束的训练。

    用 首页 今日卡片上的 继续训练 回去并点击 完成训练；如果不需要，就用 不保存并结束 丢弃后重新开始。

    切换到跑步模式时显示 有正在进行的训练。结束后才能切换。 也是同样的原因。

    健康应用连不上时

    看到 连接健康数据失败。 时，请检查设备上的健康权限。

    iPhone 请在设置 → 隐私与安全性 → 健康 → FitBoost 中，Android 请在 Health Connect 的应用权限中确认已允许 FitBoost。没有可导入的新记录。表示最近 30 天没有可导入的新训练。

    通知或锁屏不显示时

    看到 通知权限已关闭，请在系统设置中开启。时，请在设备设置中允许 FitBoost 的通知。

    实时活动关闭时，应用会提示 请在“设置”›FitBoost 中打开实时活动。还需要允许通知。也请看小组件与锁屏。

    跑步定位不到时

    显示 户外跑需要位置权限 或 位置权限已关闭，只记录时间。 时，请在设备设置中打开 FitBoost 的位置权限。

    1. iPhone 在设置 → 隐私与安全性 → 定位服务 → FitBoost 中选择“使用 App 期间”。
    2. Android 在设置 → 应用 → FitBoost → 权限 → 位置信息中选择“仅在使用该应用时允许”。

    不需要“始终”。开始跑步后，即使关掉屏幕也会一直测到这次跑步结束。正在搜索 GPS 持续很久时，请在开阔的地方稍等片刻。在跑步机这样的室内，会用步数代替位置估算距离，所以 Android 还需要允许身体活动权限。

    地图不显示时

    在无法使用地图的版本中，会不带底图、只用线画出跑过的路线，并隐藏 在地图上画。

    创建路线页面显示 此版本无法使用地图，已隐藏绘制。仍可从过去的跑步或文件创建。 就是这种情况。仍可用 过去的跑步 或 文件 创建路线，距离、分段和路线比较照常可用。显示 没有路线记录 时，表示那次跑步没有留下位置，可能是室内跑步，或当时位置权限已关闭。

    路线链接打不开时

    点路线链接会在浏览器中打开路线页面。在那里点在应用中打开的按钮，就会转到 FitBoost。

    没有安装应用时，可以在同一页面下载。显示 这不是路线链接 时，链接末尾可能被聊天软件截断了，请重新获取或改用文件。复制的链接可以通过 菜单 → 我的路线 右上角 ⋯ 中的 打开复制的链接 打开。路线页面只在浏览器内解开链接中的路线并显示，不会发送到任何地方。
