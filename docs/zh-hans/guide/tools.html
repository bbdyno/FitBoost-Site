    杠铃片计算器

    输入目标重量，就会告诉你每边要挂哪些杠铃片。免费。

    在 菜单 的 计算器 区域点击 杠铃片。杠铃杆重量和手上的杠铃片请在我的器械中设置，并用计算器里的 更改 切换器械。

    1RM 与强度计划计算器

    输入重量和次数（不超过 15 次），即可估算 1RM。

    在 1RM 计算器 中点击 用这个重量生成强度计划，会进入 强度计划计算器，用这个 1RM 计算 5×5、5/3/1、8/6/3 和 GVT 每组的重量。

    有氧、热量与宏量计算器

    在 菜单 的 计算器 区域打开有氧、热量和宏量计算器。

    • 有氧热量计算：根据跑步机速度、坡度或测功仪配速计算消耗热量。
    • 热量计算器：根据运动强度（MET）、时长和体重估算消耗热量。
    • 宏量计算器：计算目标热量以及碳水、蛋白质和脂肪。

    所有工具都集中在 菜单 → 全部工具。

    我的器械

    填好杠铃杆和杠铃片、哑铃和壶铃的间隔、器械每格配重后，杠铃片计算会按这套器械进行。

    从 菜单 → 应用设置 → 训练与例行 → 我的器械 打开。免费只能保存一个地点，保存多个地点或把推荐重量调整为这套器械能凑出的重量属于 PRO 功能。

    训练术语词典

    在 菜单 → 训练术语词典 中查找递减组、RPE 等不熟悉的词。

    术语分为组、强度、计划三类，每条都写了是什么、怎么做、什么时候用和注意事项。

    导入体成分数据

    从 CSV 或 JSON 文件导入体成分测量结果，存入身体记录。

    在 菜单 → 全部工具 → 导入体成分数据 中选择文件。

    这里没有的器械与今日推荐

    在菜单 → 应用设置 → 训练与例行 → 我的器械的这里没有的器械中选择器械后，需要这些器械的动作会从替换动作、计划生成和今日推荐中去掉。

    没有日程的日子，首页今日卡片会以今日推荐挑选主要部位恢复最好、休息最久的训练计划，并最多显示三行原因。
