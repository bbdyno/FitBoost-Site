记录训练

开始训练、记录每组、结束训练，以及修改过去的记录。

    开始训练

    在 首页 的今日卡片上点击 开始。没有例行训练时会以空白训练开始，可以自由记录。

    1. 在 首页 的今日卡片上点击 开始。
    2. 想换一个例行训练，点卡片上的 ⋯ 选择 选择例行训练。
    3. 添加动作并记录每组。

    也可以从 首页 → 我的例行 直接开始例行训练，或通过 记录 → 添加训练记录 → 开始训练 开始。

    记录每组

    填写重量和次数，点该组那一行的勾，这一组就完成了。

    • 想一次全部完成，点 完成所有组。
    • 点组号会打开该组的详细编辑。可以设置组类型（热身、递减、力竭等）、握法、强度和这一组单独的休息时间。

    记录每组强度

    完成一组后会弹出 这一组感觉如何？。从四个等级中选一个，就会用于计算下一组重量。

    想填数字，在同一窗口点 精确数值，输入 RIR（剩余次数）或 RPE（6–10）。用哪一种，可以在 菜单 → 应用设置 → 训练与例行 的 RPE/RIR 中更改。

    休息计时

    完成一组后 休息计时 开始计时。可以每次加减 10 秒，也可以暂停或跳过。

    默认休息时长、提示音、熄屏后继续计时等，可在计时器里的 休息计时设置 或设置中调整。

    动作菜单

    点动作名称旁的 ⋯，可以打开只针对该动作的菜单。

    • 替换动作：换成同一部位的其他动作。
    • 设置超级组：与另一个动作组合，交替进行。
    • 这里疼：记录疼痛部位后，用到该部位的动作会提示减重或换动作。所有方案都能用。
    • 此动作使用磅：只让这个动作用磅记录。
    • 备注 和 移除动作 也在这里。

    结束训练

    只有点击底部的 完成训练，记录才会保存。

    1. 点击 完成训练。
    2. 如果有未勾选的组，选择 记为完成 或 仅记录已勾选的。
    3. 如果是从例行训练开始的，选择是否把改动同步到例行训练。
    4. 在总结页查看训练量、时长和用到的肌肉，并留下评分和 训练备注。

    顶部菜单的 不保存并结束 会直接丢弃训练。看到 要结束训练吗？当前记录将不会保存。 时请取消，改点 完成训练。

    记录已完成的训练

    用 首页 的 快速记录 或 记录 → 添加训练记录 → 记录已完成的训练，连同日期补录过去的训练。

    同一菜单的 添加计划训练 可以把之后的训练加入日程。有进行中的训练时 快速记录 打不开，请先结束那次训练。

    编辑或删除过去的记录

    在 记录 中点记录的 ⋯，即可编辑或删除。

    • 编辑训练：修改动作和组。修改会立即反映到统计和下一组重量的计算中。
    • 编辑日期、时间和备注：调整日期或修改备注。
    • 以此记录开始训练：今天按同样的内容再练一次。
    • 删除：删除的记录无法恢复。

    记录体重和照片

    在 记录 的 身体 标签中，用 添加身体记录 记录体重、体脂率和骨骼肌量。

    体型照片在 照片 标签用 添加照片记录 记录。记录的体重会用于力量平衡的体重倍数、有氧热量计算和营养目标。体成分测量结果也可以从文件导入。

    备注

    训练中用动作的 ⋯ → 备注，结束后在总结页的 训练备注 中记录。

    像动作要领这类要反复查看的备注，请在 动作列表 中打开动作，用 添加动作备注 记录。可以附加照片或视频并置顶。所有备注都能在 菜单 → 全部备注 中集中查看。
