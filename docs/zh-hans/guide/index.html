使用指南

直接提问想做的事，或按主题浏览。

想做什么？用一句话或几个词写下来，比如“换了新手机，想把记录转过去”。

常见问题

转移到新手机连接 Garmin 手表结束训练恢复购买生成适合我的计划重量和距离单位

    • 教练与循环训练下一组重量建议、教练循环训练、每周混合训练计划和教练页的周期计划。训练中的下一组重量建议 PRO · 教练循环训练 · 每周混合训练计划 PRO+
