    重量和距离单位

    在 菜单 → 应用设置 → 通用设置 的 重量单位 中选择公斤或磅。

    杠铃片计算也会使用所选单位。同一页面还能更改 距离单位 和 每周开始日。只想让某个动作用磅记录，可在训练中点 ⋯ → 此动作使用磅。

    语言

    在 菜单 → 应用设置 → 语言 中可选择韩语、英语、日语、简体中文和繁体中文。

    选择 跟随系统 会跟随设备语言。

    外观与主题

    在 菜单 → 应用设置 → 外观 中选择浅色、深色或 跟随系统，并在 更改主题 中选择强调色。

    休息计时设置

    在 菜单 → 应用设置 → 休息计时设置 中设置默认休息时长、提示音和计时器的行为。

    • 默认休息时长、休息调整步长、休息提示音
    • 后台计时：离开应用后计时器继续运行，结束时提醒你。
    • 自动调整休息时长：根据刚完成那组的强度和动作类型决定下一次休息。你自己设置的休息，以及例行训练和计划中的休息保持不变。

    训练与例行设置

    在 菜单 → 应用设置 → 训练与例行 中调整训练页面的行为。

    • 我的器械：填写你的杠铃杆、杠铃片和哑铃。
    • RPE/RIR：选择用哪种方式记录每组强度。
    • 训练中教练建议：开关训练中的下一组重量建议。
    • 允许重复动作、滑动删除组、完成最后一组后前往下一动作

    想在训练中保持屏幕常亮，请打开 通用设置 的 训练时常亮屏幕。重量每次增加多少，在 键盘设置 的 重量步长 中设置。

    通知

    在 菜单 → 应用设置 → 通知设置 中开关 后台计时通知 和 训练计划提醒。

    收不到通知时，请在设备设置中确认已允许 FitBoost 的通知。

    小组件与锁屏

    在 菜单 → 应用设置 → 小组件与锁屏 中选择 实时活动 或 主屏幕小组件。

    • 免费可使用今日训练小组件。其他小组件、自定义和锁屏实时活动（Android 为实时通知）属于 PRO。状态、恢复和教练计划小组件属于 PRO+。
    • 实时活动需要 iOS 16.1 或更高版本。
    • iPhone：长按主屏幕，点左上角的编辑 → 添加小组件，找到 FitBoost。
    • Android：长按主屏幕，打开小组件，找到 FitBoost。

    删除所有记录

    在 菜单 → 应用设置 最下方的 删除所有记录 中删除这台设备上的全部记录。

    无法撤销。删除前请先创建备份文件。
