使用指南

入门

安装后要做的事、训练目标和主要项目，以及五个标签页的画面结构。

    本页内容

    1. 第一次打开时
    2. 训练目标
    3. 主要项目
    4. 不需要账户
    5. 画面结构

    第一次打开时

    翻过三页介绍，再一页一页选好个人信息、主要项目和经验、训练目标，就可以开始记录了。主要项目包含力量时还多一页。

    1. 翻过三页介绍，在最后一页点击 开始使用。
    2. 在 请告诉我们你的信息 一页一次填好昵称、性别、出生年份、身高和体重。出生年份、身高和体重点各自那一行来选择。
    3. 在你主要做哪种运动？中选择以力量为主、力量与跑步或以跑步为主，并在同一页下方选择训练经验（以跑步为主时为跑步经验）。主要项目包含跑步且练过的话，还可以在它下面填写最近的跑步成绩，没有就留空。主要项目只决定先显示什么，力量和跑步的功能都能用，之后可以在主要项目中更改。
    4. 选择训练目标。接近主要项目的目标排在前面，列表上方会显示所选目标的默认值（计划目标、计划有氧、饮食）。以跑步为主到这里结束。
    5. 主要项目包含力量时还多一页。选了 第一次 的人选择在哪里训练和每周几次（在健身房时还要选 这里没有的器械），并得到按所选目标生成的第一个例行。练过的人填写预估的深蹲 1RM，不知道就点 不确定 或 用举过的重量估算。

    每个问题页都可以用左上角的 返回 按钮回到上一页修改，已选的值会保留。在最后一页点 开始使用 即完成。这些信息用于推荐重量和估算消耗的热量。重量单位（kg 或 lb）跟随设备的地区设置，之后可以在设置中更改。

    训练目标

    选择训练目标后，计划生成、教练、饮食的初始值和组安排推荐都会按目标调整。

    1. 点 今天 最下方的 本周 一行，在打开的画面最上方点训练目标一行，或进入 我的 → 应用设置 → 训练目标。
    2. 从 力量、增肌、减脂、增肌减脂并行、肌肉耐力、力量与耐力、体能与健康 中选择一个。

    更改后的目标从下次训练开始生效。进行中的训练和你自己建的例行保持不变。没选过目标时，根据记录推测的目标会标注 根据记录推测。

    主要项目

    主要项目只决定力量和跑步哪个先显示，不会隐藏任何功能。

    1. 打开 我的 → 应用设置 → 主要项目。它在设置最上方、训练目标下面。
    2. 选择以力量为主、力量与跑步或以跑步为主。
    • 今天：没有今天计划的日子，最上方显示的内容按主要项目决定（以跑步为主为跑步，其余为力量）。本周画面中分组的顺序和一开始折叠的分组也会改变。以力量为主会折叠跑步分组，以跑步为主会折叠力量分组，力量与跑步两组都展开。
    • 计划：构成本周计划的内容中力量和跑步的顺序会改变。记录 → 分析第一次打开时显示主要项目的分区（力量与跑步为力量），之后打开上次查看的分区。
    • 我的：力量工具、跑步工具和计算器的顺序会改变。
    • 第一次制定每周计划时，作为侧重的初始值。

    主要项目和训练目标是两回事。目标是你想要什么（增肌、减脂等），主要项目是你做什么。1.9.0 及以前的力量模式和跑步模式已经取消。第一次打开 1.9.1 时，会按你以前用的模式设定一次主要项目，并在 今天 显示一次 力量和跑步现在不分模式一起使用。先显示的顺序可在设置的主要项目中更改。。

    不需要账户

    无需注册或登录。记录保存在这台设备上。

    昵称可在 我的 → 账户 → 编辑个人资料 中修改。记录不会发送到我们的服务器，为了在设备丢失时也能保住记录，请使用设备间同步或备份文件。

    画面结构

    底部的标签有 今天、计划、比赛、记录、我的 五个。2.0.0 把首页、记录、统计、教练、菜单改成了这样：统计移到 记录 的 分析 栏，教练、训练计划和例行移到 计划，菜单移到 我的。

    • 今天：最上方大大地显示今天要做的一件事。力量日是肌肉恢复地图，跑步日是训练结构条，比赛练习日是分段线，用它下面的按钮开始。紧接着的五个快捷入口（力量、跑步、循环训练、比赛练习、快速记录）可以直接开始其他训练。点最下方的 本周 一行，会打开有力量、跑步、身体分组的画面。休息日会显示 今天休息 和恢复地图，快捷入口照常保留。
    • 计划：有本周每天要做的训练和 构成本周计划的内容。备赛、力量教练、训练计划、我的例行、动作评估、教练循环训练、跑步教练、姿势分析、配速区间 都从这里打开。见计划页与教练画面。
    • 比赛：选择混合赛形式或自己创建，进行逐段计时的练习并查看比赛成绩分析。见备赛与练习。
    • 记录：在上方选择 记录 和 分析 栏。记录 栏是日历和过去的训练列表，用全部训练、仅力量、仅跑步标签筛选。日历的每一天会立起项目颜色的柱子（力量为桃色，跑步为天蓝色，比赛为主题色），越高表示那天练得越久。分析 栏就是以前的统计，可选择力量、跑步、身体分区。见分析栏能看到什么。
    • 我的：最上方是把今年每周做的训练按项目颜色叠起来的条和 FitBoost PRO 一行，下面是力量工具、跑步工具、健康应用连接、数据迁移与备份、发送给教练 和 计算器。应用设置 是右上角的齿轮按钮。

    本周画面中分组的顺序和一开始折叠哪些分组由主要项目决定。点分组标题折叠或展开后会记住，折叠的一行也显示本周数值。有进行中的训练或跑步时，今天最上方会变成继续进行，快捷入口中不属于正在进行项目的格子会变淡，点了会告诉你原因。升级到 2.0.0 后第一次打开时，今天会显示一次 底部标签已改为今天、计划、比赛、记录、我的。统计在记录标签的分析中，教练在计划标签中。。在 iPad 和展开的 iPhone Duo 上为两栏：左侧是每项都带实时数值的菜单，右侧一开始是恢复地图，在菜单中选择后右侧显示该内容。
