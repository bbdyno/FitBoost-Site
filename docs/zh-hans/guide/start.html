使用指南

入门

安装后要做的事、训练目标和画面结构。

    本页内容

    1. 第一次打开时
    2. 训练目标
    3. 不需要账户
    4. 界面结构

    第一次打开时

    翻过三页介绍，填写个人资料和训练经验、目标，就可以开始记录了。

    1. 翻过介绍页，在最后一页点击开始。
    2. 填写昵称、性别、出生年份、身高和体重。
    3. 选择做力量训练的时间，接着选择训练目标。
    4. 练过的话，填写预估的深蹲 1RM。不知道的话，可以选择不确定。选择 第一次 时，会询问每周几次、在哪里训练，并按所选目标生成第一个例行。

    这些信息用于推荐重量和估算消耗的热量。重量单位（kg 或 lb）跟随设备的地区设置，之后可以在设置中更改。

    训练目标

    选择训练目标后，计划生成、教练、饮食的初始值和组安排推荐都会按目标调整。

    1. 点击 首页 日期旁的目标标签，或进入 菜单 → 应用设置 → 训练目标。
    2. 从 力量、增肌、减脂、增肌减脂并行、肌肉耐力、混合训练、体能与健康 中选择一个。

    更改后的目标从下次训练开始生效。进行中的训练和你自己建的例行保持不变。没选过目标时，根据记录推测的目标会标注 根据记录推测。

    不需要账户

    无需注册或登录。记录保存在这台设备上。

    昵称可在 菜单 → 账户 → 编辑个人资料 中修改。记录不会发送到我们的服务器，为了在设备丢失时也能保住记录，请使用设备间同步或备份文件。

    界面结构

    底部的标签有 首页、记录、统计、教练、菜单 五个。

    • 首页：今天的训练、快速记录、训练计划 和 我的例行。
    • 记录：按日期查看过去的训练，并进行编辑或删除。
    • 统计：本周目标、肌肉恢复、力量平衡和训练量趋势。
    • 教练：PRO+ 的周期计划和按状态调整的指导。没有 PRO+ 时只显示介绍。
    • 菜单：应用设置、数据迁移与备份、发送给教练、计算器和健康应用连接。
