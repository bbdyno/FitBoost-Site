入门

安装后要做的事、训练目标和主要项目，以及画面结构。

    本页内容

    1. 第一次打开时
    2. 训练目标

    第一次打开时

    翻过三页介绍，填写个人资料和训练经验、目标，就可以开始记录了。

    1. 翻过介绍页，在最后一页点击开始。
    2. 填写昵称、性别、出生年份、身高和体重。
    3. 在你主要做哪种运动？中选择以力量为主、力量与跑步或以跑步为主。它只决定先显示什么，力量和跑步的功能都能用，之后可以在主要项目中更改。
    4. 选择训练经验（以跑步为主时为跑步经验），接着选择训练目标。接近主要项目的目标排在前面。
    5. 练过的话，包含力量时填写预估的深蹲 1RM，包含跑步时填写最近的跑步成绩。不知道可以跳过。主要项目包含力量并选择 第一次 时，会询问每周几次、在哪里训练，并按所选目标生成第一个例行。

    这些信息用于推荐重量和估算消耗的热量。重量单位（kg 或 lb）跟随设备的地区设置，之后可以在设置中更改。

    训练目标

    选择训练目标后，计划生成、教练、饮食的初始值和组安排推荐都会按目标调整。

    1. 点击 首页 日期旁的目标标签，或进入 菜单 → 应用设置 → 训练目标。
    2. 从 力量、增肌、减脂、增肌减脂并行、肌肉耐力、混合训练、体能与健康 中选择一个。

    更改后的目标从下次训练开始生效。进行中的训练和你自己建的例行保持不变。没选过目标时，根据记录推测的目标会标注 根据记录推测。

    主要项目

    主要项目只决定力量和跑步哪个先显示，不会隐藏任何功能。

    1. 打开 菜单 → 应用设置 → 主要项目。它在设置最上方、训练目标下面。
    2. 选择以力量为主、力量与跑步或以跑步为主。
    • 首页：分组的顺序和一开始折叠的分组会改变。以力量为主会折叠跑步分组，以跑步为主会折叠力量分组，力量与跑步两组都展开。没有今天计划的日子，最上方的卡片也按主要项目显示。
    • 统计、教练：第一次打开时显示主要项目的分区（力量与跑步为力量），之后打开上次查看的分区。
    • 菜单：力量工具、跑步工具和计算器的顺序会改变。
    • 第一次制定每周混合训练计划时，作为侧重的初始值。

    主要项目和训练目标是两回事。目标是你想要什么（增肌、减脂等），主要项目是你做什么。1.9.0 及以前的力量模式和跑步模式已经取消。第一次打开 1.9.1 时，会按你以前用的模式设定一次主要项目，并在首页显示一次 力量和跑步现已合并到同一个画面。先显示的顺序可在设置的主要项目中更改。。

    不需要账户

    无需注册或登录。记录保存在这台设备上。

    昵称可在 菜单 → 账户 → 编辑个人资料 中修改。记录不会发送到我们的服务器，为了在设备丢失时也能保住记录，请使用设备间同步或备份文件。

    画面结构

    底部的标签有 首页、记录、统计、教练、菜单 五个。力量和跑步在一个应用中一起查看。

    • 首页：最上方是今天的卡片（今天计划是跑步日时为今天的跑步，力量或循环训练日时为今天的训练），下方紧接着是另一项运动的开始按钮（开始跑步或开始力量训练），再往下是力量、跑步、身体分组。力量分组里有 快速记录、训练计划 和 我的例行。
    • 记录：按日期查看过去的训练，并进行编辑或删除。用全部训练、仅力量、仅跑步标签筛选。
    • 统计：在上方选择力量、跑步、身体分区。力量为本周目标、肌肉恢复、力量平衡和训练量趋势，跑步为距离、配速区间和预测成绩，身体为体成分、体重和心肺适能。
    • 教练：最上方的公共区有本周计划、干扰提示和混合赛备赛，下面选择力量、跑步、身体·营养分区。见教练页的结构。
    • 菜单：应用设置、数据迁移与备份、发送给教练、力量和跑步工具、计算器和健康应用连接。

    分组的顺序和一开始折叠哪些分组由主要项目决定。点分组标题折叠或展开后会记住，折叠的一行也显示本周数值。有进行中的训练或跑步时，最上方的卡片会变成继续进行，没有另一项运动的开始按钮。在 iPad 和展开的 iPhone Duo 上为两栏：左侧是每项都带实时数值的菜单，右侧一开始是恢复地图，在菜单中选择后右侧显示该内容。
