例行训练与计划

创建例行训练、生成适合自己的计划、使用动作列表。

    本页内容

    1. 创建例行训练
    2. 编辑、复制、删除例行训练
    3. 自动加重 PRO

    5. 跟练现成计划
    6. 自定义动作
    7. 动作列表与动作指南

    创建例行训练

    在 首页 的 我的例行 区域点击 添加。

    1. 在 首页 的 我的例行 区域点击 添加。
    2. 选择 新建空白例行训练 或 从历史记录导入。
    3. 添加动作和组，然后保存。

    免费最多可建 3 个例行训练，PRO 不限。结束训练时也可以把改动同步到例行训练。

    编辑、复制、删除例行训练

    在例行训练页面点例行训练的 ⋯，会出现 编辑例行训练、复制例行训练、删除例行训练。

    例行训练页面可从 首页 今日卡片的 ⋯ → 选择例行训练 打开。页面有 我的例行、热门与公开、训练计划 三个标签，可在 热门与公开 中从 FitBoost 推荐 选用。

    删除例行训练时，用它安排的日程和提醒也会一并删除。

    自动加重 PRO

    在编辑例行训练时打开 自动加重，上次每组都达到目标次数的动作，下次会自动加重。

    训练中逐组提示下一组重量的功能，请看训练中教练建议。

    生成适合我的计划

    选择目标、时间和器械，就会生成一周的计划并存为例行训练。

    1. 点击 首页 → 训练计划 → 生成适合我的计划。
    2. 选择目标、训练经验、每周天数、每次时长和器械（健身房、在家哑铃、徒手）。
    3. 设置有氧、想重点练的部位和想休息的部位，点击 生成。
    4. 查看预览并存为例行训练。

    重量不会预先填入，而是在训练当天根据记录决定。免费可在 3 个例行训练的上限内保存，换一种组合 和 更换动作重新生成 为 PRO 功能。

    跟练现成计划

    在 首页 → 训练计划 下方选择现成的计划并点击 开始计划，日程就会加入首页。

    同一页面上方有 生成适合我的计划、教练循环训练 和 每周混合训练计划 的入口。

    自定义动作

    列表里没有的动作，用 动作列表 → 添加自定义动作 创建。

    可设置记录方式（重量与次数、时间等）、主要肌肉，以及是否为单侧动作。免费最多 5 个，PRO 不限。

    动作列表与动作指南

    在 菜单 → 动作列表 中搜索 1,690 个动作，打开后可查看做法和注意事项。

    每个动作都有 说明、注意事项、技巧、我的记录与统计，以及 替代动作，点 记录这个动作 可直接开始记录。可按名称搜索或按部位、器械筛选，常练的动作可以收藏。

    用文件收发训练计划

    在训练计划 ⋯ → 分享例行训练，训练计划文件会通过分享面板发出。对方点开文件并用 FitBoost 打开即可。

    打开收到的文件时会询问要导入这个训练计划吗？，保存后加入我的训练计划。免费版最多 3 个训练计划。
