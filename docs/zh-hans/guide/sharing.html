记录分享与装饰

把跑步和力量训练记录做成分享卡片，用编辑器调整字体、颜色和照片，并保存为我的模板。

    本页内容

    1. 选择分享卡片
    2. 打开装饰编辑器
    3. 字体、颜色与照片
    4. 放到人物后面 PRO
    5. 我的模板与自动生成
    6. 分享与装饰的免费与付费

    选择分享卡片

    在跑步结果中点 分享记录，从 路线、分段、叠在照片上、贴纸 卡片中选一种，做成快拍或帖子尺寸。

    1. 在跑步结果页面点 分享记录。过去的跑步可在 记录 中打开。
    2. 在上方的标签行选择卡片，再选择 快拍 9:16 或 帖子 4:5 尺寸和背景色。
    3. 打开或关闭 显示路线、显示平均心率、显示爬升 等项目。
    4. 点 分享到 Instagram 快拍 会直接打开 Instagram 快拍。要发到别处或保存到相册，请用 用其他应用分享。

    贴纸 卡片背景透明，会作为可移动的贴纸放进快拍。路线只按截掉起点和终点附近及隐私区域后的线绘制，卡片中不含底图、坐标和时刻（含日期）。力量训练可在 记录 中打开记录后用 分享训练摘要，或在 统计 中用 分享记录卡片，以同样方式制作卡片。

    打开装饰编辑器

    点跑步或力量训练分享页面上方的魔杖按钮（自定义），即可打开装饰编辑器。

    1. 点分享页面右上角的魔杖按钮。
    2. 从下方栏打开 贴纸、字体、颜色、照片、图层、我的模板。
    3. 加入贴纸后用手指拖动，或调整大小和旋转。用 添加文字 也可以加文字。
    4. 在 尺寸 中选择 快拍 9:16、帖子 4:5 或 正方形，完成后导出或发到快拍。

    跑步贴纸有距离、时间、配速、海拔剖面和跑过的路线，力量贴纸有 今日训练、个人纪录、三大项总和、比上次增加的训练量、组、训练部位 等。坡度修正配速或估算 1RM 走势这类分析值贴纸，按该值原本所属的等级开放。卡片上的应用名称标识与等级无关，始终会显示。

    字体、颜色与照片

    即使在同一个贴纸里，也能为 数字、单位、标签 分别选择字体和颜色。照片可以从黑白、模糊调整到亮度、对比度。

    • 字体：每个部分的字体、大小、字距、等宽数字。字体中没有的字会提示 此字体没有的字符会用默认字体显示。
    • 颜色：基本 3 色、从照片中取的颜色、取色器、颜色代码。会显示对比度以判断文字是否清晰，并建议 添加阴影。
    • 照片：黑白、模糊、亮度、对比度、色温、底部变暗。
    • 路线：单色，或按 配速、坡度 给线上色。
    • 图层：撤销、重做、上移、下移、隐藏、锁定、位置与旋转数值、显示快拍遮挡区域。

    共有 22 种字体，全部以 SIL 开源字体许可（OFL）收录在应用中。免费可在整个贴纸上使用 3 种基本字体，以及基本 3 色、黑白、模糊和单色路线。每个部分单独选字体和其余字体、照片取色、吸管、色码、撤销、图层、数值、遮挡区域、路线上色，以及亮度、对比度、暖色、底部变暗属于 PRO。

    放到人物后面 PRO

    在 照片 中打开 放到人物后面，会抠出照片中的人物，让贴纸位于人物后面。照片只在设备内处理。

    1. 在 叠在照片上 卡片或编辑器中选择照片作为背景。
    2. 在 照片 中打开 放到人物后面。

    仅在本机抠出照片中的人物，让贴纸位于人物后方。iPhone 使用设备自带的视觉功能，Android 使用应用内置的人物分割模型，因此照片不会发送到任何地方。人物太小或模糊时会显示 照片中没有找到人物。

    我的模板与自动生成

    用 将当前布局存为模板 保存装饰好的布局、字体和颜色，下次记录的数值会直接填进去（PRO）。

    1. 在编辑器中排好布局后，点 我的模板 中的 将当前布局存为模板。
    2. 下次分享时在 我的模板 中选择该模板，就会填入新记录的数值。
    3. 打开模板的 完成后自动用此模板生成 开关后，训练或跑步结束时可从结果页面的 用我的模板分享 直接打开（PRO+）。

    我的模板只保存在本设备和备份文件中，不会通过设备间同步上传。订阅结束后，已保存的模板不会删除，只是 PRO 功能重新锁定。

    分享与装饰的免费与付费

    分享卡片和基本装饰免费。专业编辑工具属于 PRO，结束后用我的模板直接生成属于 PRO+。

    • 免费：跑步与力量分享卡片，贴纸的添加、拖动、大小与旋转，3 种基本字体，基本 3 色，黑白与模糊，单色路线，快拍、帖子与正方形尺寸，导出和直接发到 Instagram 快拍。
    • PRO：每个部分的字体、大小、字距与数字宽度，其余字体，照片取色、吸管与色码，撤销、图层、数值与快拍遮挡区域，路线上色，亮度、对比度、暖色与底部变暗，放到人物后面，我的模板。
    • PRO+：训练或跑步结束时用我的模板直接生成分享卡片。

    卡片上的应用名称标识在所有等级中都会显示，没有去除功能。
