常见问题

需要注册账户吗？

不需要。安装后即可开始记录。记录保存在设备上，我们不要求注册。

更换设备后，记录会怎样？

相同操作系统的设备之间，请开启菜单 → 应用设置 → 设备间同步。iPhone、iPad 通过 iCloud，Android 通过 Google 云端硬盘，在使用同一账户的设备之间同步记录。同步免费，不会同步照片、视频文件和订阅状态。

如需在 iPhone 与 Android 之间迁移，或以文件形式保存，请在菜单 → 数据迁移与备份 → 创建备份文件中生成文件并发送到新设备，再在同一页面通过导入备份文件打开。创建文件、替换记录和设置密码均免费；将文件合并到现有记录需要 PRO。

如已开启设备备份（iCloud 或 Google 自动备份），在新设备上恢复应用时记录也会一并迁移。

免费版可以用到什么程度？

训练记录免费且不限数量。例行训练最多可创建 3 个，自定义动作最多 5 个。

1,690 个动作及动作指南、3·5·8·10 次的预估重量、杠铃片计算、设备间同步、公斤和磅两种单位，以及发送给教练，也都免费。

PRO 和 PRO+ 有什么区别？

PRO 会计算下次该用多少重量，包括例行训练自动加重、1–15 次个人次数-重量曲线、训练中教练、从自身记录学习的标准、力量平衡方案、停滞检测、匹配器械的推荐重量和每周训练报告，并且例行训练、自定义动作和收到的学员记录均不限数量。

PRO+ 在 PRO 全部功能的基础上，增加分块周期化计划、根据当天状态调整强度、按肌肉调整每周组数、营养目标以及热身组自动填写。

两者均提供按月或按年订阅。

如何取消订阅？

付款通过 Apple 或 Google 账户处理，因此也需在相应平台取消。

  • iOS：设置 → 你的姓名 → 订阅
  • Android：Play 商店 → 个人资料 → 付款和订阅 → 订阅

如未在续订日前至少 24 小时取消，订阅可能会自动续订。

更换设备后看不到 PRO

请点按菜单 → FitBoost PRO → 恢复购买。需要登录购买时使用的 Apple 或 Google 账户。

订阅与付款的商店账户绑定，因此在 iPhone 上购买的订阅无法在 Android 上恢复，反之亦然。

下次重量是如何计算的？

根据 12 次及以下的已完成组，取 Epley、Brzycki、Lombardi 公式估算值的中位数作为 1RM。如记录 RIR，还会计入剩余可做次数。记录积累后，也会结合每个动作自身的次数-重量特性。

推荐值仅为制定训练计划的参考，并非医疗建议。如出现疼痛或异常疲劳，请降低重量并咨询专业人士。

可以用磅记录吗？

可以。在菜单 → 应用设置 → 通用设置 → 重量单位中选择公斤或磅。杠铃片计算也会使用所选单位。

如何更改语言？

在菜单 → 应用设置 → 语言中，可选择 한국어、English、日本語、简体中文、繁體中文。选择“跟随系统”则使用设备语言。

如何更改主题颜色？

在菜单 → 应用设置 → 更改主题中，可从六种颜色中选择。

可以与教练共享记录吗？

可以。在菜单 → 发送给教练中选择时间范围，应用会生成报告（PDF）和学员文件，可通过即时通讯工具、电子邮件等任意应用发送，不经过我们的服务器。

教练用 FitBoost 打开收到的文件后，可在菜单 → 学员记录中查看。收到的记录不会与教练本人的记录混在一起。免费版可查看 1 名学员，PRO 不限人数。

当前发布版本没有查找好友等社交功能。

可以在智能手表上使用吗？

支持 Apple Watch（搭配 iPhone）、Galaxy Watch 等 Wear OS 手表（搭配 Android）以及 Garmin 手表（搭配 iPhone 或 Android）。在手表上完成一组并选择强度后，休息计时器会开始计时，结束时以振动提醒。在手表上完成的训练会存入手机的记录。

请在手机的菜单 → 应用设置 → 智能手表设置中开启智能手表同步。使用 Garmin 时，请先从 Connect IQ 商店将 FitBoost 安装到手表上，再在同一页面点按连接 Garmin 手表。用 Garmin 手表完成的训练也会以力量训练活动保存到 Garmin Connect。

可以帮我制定训练计划吗？

在首页 → 训练计划 → 生成适合我的计划中，选择目标、训练经验、每周天数、每次时长和器械，应用会生成每周计划并保存为例行训练。

免费版可在 3 个例行训练的上限内保存；查看其他组合和更换动作重新生成为 PRO 功能。

避免丢失记录

  • 请开启设备间同步或设备备份。
  • 不时通过创建备份文件另存一份文件。
  • 删除应用后，设备上的应用数据也会一并删除。
