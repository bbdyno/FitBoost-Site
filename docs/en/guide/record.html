Logging workouts

Start a workout, log sets, finish, and fix past records.

    Starting a workout

    Tap Start on today's card in Home. If you have no routine, you start an empty workout and log freely.

    1. Tap Start on today's card in Home.
    2. To use a different routine, tap ⋯ on the card and pick Choose a routine.
    3. Add exercises and log your sets.

    You can also start a routine straight from Home → My routines, or go to Record → Add workout record → Start workout.

    Logging sets

    Enter the weight and reps, then tap the check on the set row to finish that set.

    • To finish them all at once, tap Complete all sets.
    • Tap the set number to open the set details. Choose the set type (warm-up, drop, failure, and more), grip, effort, and a rest time for that set only.

    Logging effort

    When you finish a set, How did that set feel? pops up. Pick one of four levels and it feeds into the next-weight calculation.

    To enter a number, tap Exact value in the same sheet and enter RIR (reps left) or RPE (6–10). Choose which one you use under RPE/RIR in Menu → App settings → Workout & routines.

    Rest timer

    The Rest timer starts when you finish a set. Add or remove 10 seconds, pause, or skip it.

    Set the default rest, alert sound, and whether it keeps running in the background from Rest timer settings inside the timer, or in settings.

    Exercise menu

    Tap ⋯ next to an exercise name to open options for that exercise only.

    • Swap exercise: replace it with another exercise for the same muscles.
    • Set up superset: pair it with another exercise and alternate.
    • This hurts: log where it hurts, and exercises that use that area will suggest a lighter weight or a swap. Available on every plan.
    • Use lb for this exercise: log just this exercise in pounds.
    • Notes and Remove exercise are here too.

    Finishing a workout

    Your workout is saved only when you tap Finish workout at the bottom.

    1. Tap Finish workout.
    2. If some sets aren't checked, choose Log as done or Log checked sets only.
    3. If you started from a routine, choose whether to save your changes to the routine.
    4. On the summary, review volume, time, and muscles used, and add a rating and Workout notes.

    End without saving in the top menu discards the workout. If you see End this workout? The current record won't be saved., cancel and tap Finish workout instead.

    Logging a past workout

    Use Quick record in Home or Record → Add workout record → Log a past workout to enter a workout with its date.

    Schedule a workout in the same menu puts a future workout on your schedule. Quick record won't open while a workout is in progress, so finish that one first.

    Editing or deleting past workouts

    In Record, tap ⋯ on a workout to edit or delete it.

    • Edit workout: change exercises and sets. Stats and next-weight calculations update right away.
    • Edit date, time and note: move the date or change the note.
    • Start from this record: do the same workout again today.
    • Delete: deleted workouts can't be recovered.

    Body weight and photos

    In the Body tab of Record, use Add body record to log weight, body fat, and skeletal muscle mass.

    Progress photos go in the Photos tab with Add photo record. Your logged weight is used for strength-to-bodyweight levels, cardio calorie estimates, and nutrition targets. You can also import body composition from a file.

    Notes

    During a workout, use ⋯ → Notes on an exercise. Afterwards, use Workout notes on the summary.

    For notes you'll keep coming back to, like form cues, open the exercise in Exercise list and use Add exercise note. You can attach photos or videos and pin notes to the top. See every note in Menu → All memos.
