    무게·길이 단위

    메뉴 → 앱 설정 → 일반 설정의 무게 단위에서 킬로그램과 파운드 중 고릅니다.

    원판 계산도 고른 단위로 합니다. 같은 화면에서 길이 단위와 한 주의 시작 요일도 바꿉니다. 운동 하나만 파운드로 기록하려면 운동 중 ⋯ → 이 운동은 파운드로를 누릅니다.

    언어

    메뉴 → 앱 설정 → 언어에서 한국어, English, 日本語, 简体中文, 繁體中文 중 고릅니다.

    시스템 설정을 고르면 기기 언어를 따라갑니다.

    화면 모드와 테마

    메뉴 → 앱 설정 → 화면 모드에서 라이트·다크·기기 설정 따르기 중 고르고, 테마 변경에서 강조 색을 고릅니다.

    휴식 타이머 설정

    메뉴 → 앱 설정 → 휴식 타이머 설정에서 기본 휴식 시간과 알림음, 타이머 동작을 정합니다.

    • 기본 휴식시간, 휴식시간 설정 간격, 휴식시간 알림음
    • 백그라운드 타이머: 앱을 나가도 타이머가 돌고 끝나면 알립니다.
    • 휴식 시간 자동 조절: 방금 세트의 강도와 운동 종류로 다음 휴식을 정합니다. 직접 정한 휴식과 루틴·계획의 휴식은 그대로 둡니다.

    운동·루틴 설정

    메뉴 → 앱 설정 → 운동·루틴 설정에서 운동 화면의 동작을 바꿉니다.

    • 내 장비: 가진 봉·원판·덤벨을 넣습니다.
    • RPE/RIR: 세트 강도를 어느 쪽으로 받을지 고릅니다.
    • 운동 중 코치 추천: 운동 중 다음 무게 추천을 켜고 끕니다.
    • 같은 운동 중복 허용, 밀어서 세트 삭제, 마지막 세트 완료 후 다음 운동으로 이동

    운동 중 화면이 꺼지지 않게 하려면 일반 설정의 운동 중 화면 항상 켜기를 켭니다. 무게를 몇 단위씩 올릴지는 키보드 설정의 무게 입력 간격에서 정합니다.

    알림

    메뉴 → 앱 설정 → 푸시 알림 설정에서 백그라운드 타이머 알림와 운동 일정 알림을 켜고 끕니다.

    알림이 오지 않으면 기기 설정에서 FitBoost 알림이 허용되어 있는지 확인하세요.

    위젯과 잠금화면

    메뉴 → 앱 설정 → 위젯·잠금화면에서 라이브 액티비티와 홈 화면 위젯을 고릅니다.

    • 무료는 오늘 운동 위젯을 씁니다. 다른 위젯과 꾸미기, 잠금화면 라이브 액티비티(Android는 라이브 알림)는 PRO입니다. 컨디션·회복·코치 계획 위젯은 PRO+입니다.
    • 라이브 액티비티는 iOS 16.1 이상에서 됩니다.
    • iPhone: 홈 화면을 길게 누르고 왼쪽 위 편집 → 위젯 추가에서 FitBoost를 찾습니다.
    • Android: 홈 화면을 길게 누르고 위젯에서 FitBoost를 찾습니다.

    모든 기록 삭제

    메뉴 → 앱 설정 맨 아래 모든 기록 삭제로 이 기기의 기록을 모두 지웁니다.
