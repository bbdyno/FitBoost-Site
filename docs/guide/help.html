문제 해결

시계 연결, 동기화, 백업, 구독, 달리기 위치에서 막힐 때 확인할 것입니다.

    4. 백업 파일이 열리지 않을 때

    시계가 연결되지 않을 때

    메뉴 → 앱 설정 → 스마트워치 설정의 시계 연결 상태에 뜨는 문구로 원인을 찾습니다.

    • 연결된 시계가 없습니다.: 휴대폰과 시계가 짝지어져 있는지 시계 앱(Watch 앱·Galaxy Wearable)에서 확인하세요.
    • 시계에 FitBoost를 설치해 주세요.: Apple Watch나 갤럭시 워치에 FitBoost를 설치하세요.
    • 시계 연결 대기 중: 시계에서 FitBoost를 한 번 열어 두세요.
    • 이 기기에서는 시계를 지원하지 않습니다.: 이 휴대폰에서는 시계를 쓸 수 없습니다.

    스마트워치 연동가 켜져 있는지도 확인하세요. 운동을 시계로 보내려면 휴대폰에서 운동을 먼저 시작해야 합니다.

    가민이 연결되지 않을 때

    가민 시계 연결를 누르면 뜨는 문구를 따라갑니다.

    • 가민 커넥트 앱을 먼저 설치해 주세요.: 휴대폰에 가민 커넥트 앱을 설치하고 시계를 연결합니다.
    • 가민 커넥트 앱에서 시계를 골라 주세요.: 가민 커넥트 앱이 열리면 FitBoost를 쓸 시계를 고릅니다.
    • 시계에 FitBoost를 설치해 주세요. 누르면 Connect IQ 스토어가 열립니다.

    시계에서 FitBoost를 열었는데 운동이 안 오면 휴대폰에서 운동을 먼저 시작했는지 확인하세요. 자세한 순서는 가민 시계 연결하기에 있습니다.

    동기화가 안 될 때

    메뉴 → 앱 설정 → 기기 간 동기화에 뜨는 문구를 확인합니다.

    • 아이클라우드에 로그인되어 있지 않습니다. 설정 앱에서 애플 계정에 로그인해 주세요
    • 구글 드라이브 권한이 필요합니다. 지금 동기화를 눌러 다시 허용해 주세요
    • 아이클라우드 저장 공간이 가득 찼습니다 / 구글 계정 저장 공간이 가득 찼습니다: 저장 공간을 비우거나 늘리세요.
    • 다른 기기가 더 새 버전의 앱으로 저장했습니다. 앱을 업데이트해 주세요
    • 인터넷에 연결되지 않아 잠시 뒤 다시 시도합니다

    두 기기가 같은 iCloud 또는 Google 계정인지, 둘 다 동기화를 켰는지 확인하세요. iPhone과 Android끼리는 동기화되지 않습니다. 백업 파일로 옮기세요.

    백업 파일이 열리지 않을 때

    불러오기에 실패해도 이 기기의 기록은 그대로입니다. 뜬 문구를 확인하세요.

    • FitBoost 백업 파일이 아닙니다.: .fitboost 파일인지 확인하세요.
    • 더 새로운 앱에서 만든 파일입니다. 앱을 업데이트한 뒤 불러오세요.
    • 파일이 손상되어 불러오지 않았습니다. 이 기기의 기록은 그대로입니다.: 파일을 다시 받아 보세요.
    • 암호가 맞지 않습니다.: 만들 때 건 암호를 넣어야 합니다. 잊은 암호는 찾을 수 없습니다.
    • 회원 파일이 아니에요. 내 기록 백업은 데이터 옮기기·백업에서 불러와 주세요.

    구독했는데 PRO가 안 보일 때

    FitBoost PRO 화면에서 구매 복원을 누르세요.

    결제한 Apple 또는 Google 계정으로 로그인되어 있어야 합니다. iPhone에서 산 구독은 Android에서, Android에서 산 구독은 iPhone에서 복원되지 않습니다. 자세한 내용은 구매 복원을 보세요.

    방금 한 운동이 기록에 없을 때

    운동을 운동 종료로 끝냈다면 저장되지 않습니다. 기록은 운동 완료을 눌러야 남습니다.

    이미 없어진 운동은 기록 → 운동 기록 추가 → 이미 한 운동 기록하기로 다시 적어 넣을 수 있습니다. 가민 시계로 한 운동이라면 휴대폰을 가까이 두고 시계 앱에서 다시 보내 보세요.

    진행 중인 운동이 있다고 할 때

    진행 중인 운동을 먼저 완료해 주세요. 문구가 뜨면 열려 있는 운동이 있는 것입니다.

    홈 오늘 카드의 운동 계속 버튼으로 돌아가 운동 완료을 누르거나, 필요 없으면 운동 종료로 버린 뒤 다시 시작하세요.

    러닝 모드로 바꿀 때 진행 중인 운동이 있어요. 끝낸 뒤에 바꿀 수 있어요.가 뜨는 것도 같은 까닭입니다.

    건강 앱 연결이 안 될 때

    건강 데이터 연결에 실패했습니다. 문구가 뜨면 기기의 건강 앱 권한을 확인합니다.

    iPhone은 설정 → 개인정보 보호 및 보안 → 건강 → FitBoost에서, Android는 Health Connect의 앱 권한에서 FitBoost가 허용되어 있는지 확인하세요. 새로 가져올 운동이 없습니다.는 최근 30일에 새로 가져올 운동이 없다는 뜻입니다.

    알림·잠금화면이 안 보일 때

    알림 권한이 꺼져 있습니다. 기기 설정에서 켜 주세요.

    잠금화면 라이브 액티비티가 꺼져 있으면 앱이 설정 앱 › FitBoost에서 실시간 현황을 켜 주세요라고 안내합니다. 알림도 허용해야 보입니다. 위젯과 잠금화면도 보세요.

    달리기 위치가 잡히지 않을 때

    밖에서 재려면 위치 권한이 필요해요 또는 위치 권한이 꺼져 있어요. 시간만 재요.가 뜨면 기기 설정에서 FitBoost의 위치 권한을 켭니다.

    1. iPhone은 설정 → 개인정보 보호 및 보안 → 위치 서비스 → FitBoost에서 앱을 사용하는 동안을 고릅니다.
    2. Android는 설정 → 애플리케이션 → FitBoost → 권한 → 위치에서 앱 사용 중에만 허용을 고릅니다.

    항상 허용은 필요 없습니다. 달리기를 시작한 뒤에는 화면을 꺼도 그 달리기가 끝날 때까지 잽니다. 위성 찾는 중이 오래 가면 하늘이 트인 곳에서 잠시 기다려 주세요. 러닝머신처럼 실내에서는 위치 대신 걸음으로 거리를 어림하므로, Android에서는 신체 활동 권한도 허용해 주세요.

    지도가 보이지 않을 때

    지도를 쓸 수 없는 판에서는 바탕 지도 없이 달린 길을 선으로만 그리고, 지도에 그리기를 숨깁니다.

    코스 만들기 화면에 이 빌드에서는 지도를 쓸 수 없어 그리기를 숨겼어요. 지난 달리기나 파일로 만들 수 있어요.라고 뜨면 이 경우입니다. 지난 달리기이나 파일로 코스를 만들 수 있고, 거리·구간·코스 비교는 그대로 됩니다. 위치 기록이 없어요이 뜨면 그 달리기에는 위치가 남지 않은 것입니다. 실내 달리기였거나 위치 권한이 꺼져 있던 경우입니다.

    코스 링크가 열리지 않을 때

    코스 링크를 누르면 브라우저에 코스 페이지가 열립니다. 거기서 앱으로 여는 버튼을 누르면 FitBoost로 넘어갑니다.

    앱이 없으면 같은 페이지에서 받을 수 있습니다. 코스 링크가 아니에요가 뜨면 메신저에서 링크 끝이 잘렸을 수 있으니 다시 받거나 파일로 받아 주세요. 복사한 링크는 메뉴 → 내 코스 오른쪽 위 ⋯의 복사한 링크 열기로 엽니다. 코스 페이지는 링크 안의 코스를 브라우저 안에서만 풀어 보여 주고 어디에도 보내지 않습니다.
