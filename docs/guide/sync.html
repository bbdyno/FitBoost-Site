동기화와 백업

기기끼리 기록을 맞추고, 새 휴대폰으로 옮기고, 백업 파일을 만드는 방법입니다.

    이 페이지에서

    1. 기기 간 동기화
    2. 동기화되지 않는 것
    3. 새 휴대폰으로 옮기기
    4. 백업 파일 만들기
    5. 백업 파일 불러오기
    6. 기록을 잃지 않으려면

    기기 간 동기화

    같은 계정의 기기끼리 기록을 자동으로 맞춥니다. iPhone·iPad는 iCloud, Android는 Google Drive를 씁니다. 무료입니다.

    1. 메뉴 → 앱 설정 → 기기 간 동기화을 엽니다.
    2. 동기화를 켭니다. 바로 맞추려면 지금 동기화를 누릅니다.
    3. 다른 기기에서도 같은 계정으로 똑같이 켭니다.

    기록은 저희 서버를 거치지 않고 여러분의 iCloud나 Google Drive에만 저장됩니다.

    동기화되지 않는 것

    사진·동영상 파일과 구독, 진행 중인 운동은 기기마다 따로입니다.

    • 사진·동영상 파일은 옮기지 않습니다. 메모 글은 맞춰집니다.
    • 구독, 진행 중인 운동, 건강 앱·시계 연결, 지금 고른 장비는 기기마다 따로 둡니다.
    • iPhone과 Android처럼 운영체제가 다른 기기끼리는 자동으로 맞추지 않습니다. 백업 파일로 옮기세요.

    새 휴대폰으로 옮기기

    같은 운영체제끼리는 기기 간 동기화나 기기 백업으로, iPhone과 Android 사이는 백업 파일로 옮깁니다.

    1. 예전 휴대폰에서 메뉴 → 데이터 옮기기·백업 → 백업 파일 만들기를 누릅니다.
    2. 만든 파일을 메신저·메일·클라우드 같은 방법으로 새 휴대폰에 보냅니다.
    3. 새 휴대폰에서 메뉴 → 데이터 옮기기·백업 → 백업 파일 불러오기로 그 파일을 엽니다.
    4. 바꾸기를 고릅니다.

    같은 운영체제라면 기기 간 동기화를 켜 두는 것만으로도 됩니다. 기기 백업(iCloud 백업·Google 자동 백업)이 켜져 있다면 새 기기에서 앱을 복원할 때도 함께 넘어갑니다. 구독은 파일로 옮겨지지 않으니 구매 복원을 보세요.

    백업 파일 만들기

    메뉴 → 데이터 옮기기·백업 → 백업 파일 만들기로 기록 전체를 파일 하나로 만듭니다. 무료입니다.

    운동 기록, 루틴, 일정, 신체 기록, 사진, 설정이 들어갑니다. 암호를 걸 수 있는데, 암호를 잊으면 파일을 열 수 없으니 따로 적어 두세요.

    백업 파일 불러오기

    메뉴 → 데이터 옮기기·백업 → 백업 파일 불러오기에서 .fitboost 파일을 고르고, 바꾸기와 합치기 중 하나를 고릅니다.

    • 바꾸기(무료): 이 기기의 기록을 지우고 파일 내용으로 바꿉니다. 바꾸기 전 기록은 자동으로 백업해 두어 되돌릴 수 있습니다.
    • 합치기(PRO): 지금 기록에 파일 내용을 더합니다. 같은 기록은 나중에 고친 쪽이 남고, 한쪽에서 지운 기록은 다시 나타납니다.

    기록을 잃지 않으려면

    기록은 이 기기에 저장되므로, 앱을 지우면 기기에 있던 기록도 함께 지워집니다.

    • 기기 간 동기화나 기기 백업을 켜 두세요.
    • 가끔 백업 파일을 만들어 따로 보관하세요.
